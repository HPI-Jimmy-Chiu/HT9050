# HT9045 Shuttle

## 差異

| 相對通用／HT9050 | HT9045 |
|---|---|
| 入口 | Do_Auto_SHT1／Do_Auto_SHT2 |
| 軸與 Kit | 前／後軌各一個 MInShuttle1／MInShuttle2 軸，同軌 In-Kit／Out-Kit 隨托板一起動；不是 HT9050 的獨立 In/Out X |
| 停位 | 同軌用 Prod.InSHT[n].iLeft/iRight，三站雙 Kit 對照見歷史正文 §6 |
| Task | AutoSHT1Task／AutoSHT2Task 分別屬 SHT1／SHT2；HT9050 第二游標則屬 OutSH |
| 條件 | 互鎖依版本、站點與機型旗標，不能由 common 推論可移動 |

## 入口與流程

V906 csystem.cpp::DoAllProcess 的非 Type_HT9050 分支按 bDoProcess 呼叫 SHT1/SHT2；該 else 也服務其他機型，
函式內仍須核對 MachineTypeChoice／TestMode／站點／功能旗標，不把整個 else 當作同一機型。

按問題讀 [ProcessFlow](ht9045/Do_Auto_SHT1_SHT2_ProcessFlow.md)、[BarcodeFlow](ht9045/Shuttle_OCR_2DID_BarcodeFlow.md)、
[PreScan](ht9045/NN_2DID_PreScan_DuringIndexDown.md)、[OutKitStuck](ht9045/OutKitStuck_Detect_WAR0495.md)。
來源版別保留；尤其 NN 預掃文件不代表 V906 已完整實作。

## 安全

依 [SafetyInterlock](ht9045/Shuttle-Arm-Safety-Interlock.md) 核對 fCanMoveR/fCanMoveM、DoInOutARM_SHT_MoveSafe、OutSHTxInRT 的實際呼叫處。
Timeout 不是馬達故障的充分證據；沿等待條件與 MotorMove 回傳追查。先留 State Record 再做清狀態的 OK／HOME。
