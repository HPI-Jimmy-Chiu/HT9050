# HT9050 Shuttle

## 差異

| 相對通用／HT9045 | HT9050 |
|---|---|
| 機構 | In／Out 各一個 X 軸；沒有前／後第二組 Shuttle |
| 軸名 | M11 MInShuttle1＝In X；M17 MOutShuttle1＝Out X；M18 MOutShuttle2＝出料飛梭 Y 軸 |
| 入口 | Do_Auto_InSH／Do_Auto_OutSH，不是同軌兩 Kit 的 SHT1/SHT2 模型 |
| Task | AutoSHT1Task＝InSH；AutoSHT2Task＝OutSH，與舊入口共用游標，按機型只跑一組 |
| 測區 | In X 進入前等 Out X 退到 Right 且停止；Out X 移動核對 Out Y 與 OutArm ZA |

## 入口與流程

V906 csystem.cpp::DoAllProcess 在 MachineTypeChoice==Type_HT9050 時按 bDoProcess 交替呼叫 InSH／OutSH，此分支不呼叫 Do_Auto_SHT3。
這是程式分派條件，不代表當前機台已選此身分；機台快照依 AGENTS.md 確認。

| 函式／Task | 動作 |
|---|---|
| Do_Auto_InSH 1／10 | 核對可移動、Z1 安全與料況，選 100／200 |
| Do_Auto_InSH 100 | In X 回 Prod.InSHT[0].iLeft，成功後開放 Out X fCanMove |
| Do_Auto_InSH 200 | 等 Out X 退到 Right 及 Z1 guard，再進 iRight；到位且 Out X 在 Right 時鎖 Out X |
| Do_Auto_OutSH 1／10 | 核對可移動、Z1 與已測料，選 100／200 |
| Do_Auto_OutSH 100 | In X 在 Left 才進測區 iLeft；Out X 到位後鎖 In X |
| Do_Auto_OutSH 200 | Out X 退到 iRight，成功後開放 In X；FRCarryKit 有料時等 Out Y 到 Right 才結束本步 |
| Do_Auto_OutSH 201 | 殘料重試；正常 case 100 的進入條件有原註明的可達性問題，不能因有 case 就認定會走到 |

case 100 的 b1ShuttleMoveToLeft 與 InSHT1InLF 關係、retry 計數問題見原註解；本次不改行為。

## 安全

- W906_Ht9050Z1AtSafe（InSH／OutSH case 1）：Z1 ReadPos 與 Prod.TestZ1_Safe 的差值須落在 ±10（含端點）；來源為 main 的 F9050-FIX2／Frank 20261006 裁決，套用位置限這兩個入口的 case 1。
- W906_Ht9050InSht1ToIndexBlocked（InSH 200）：Out X 未在 Right 且停止時停 In X 並等；另沿用 Z1 guard。
- W906_Ht9050OutSht1MoveBlocked（OutSH 100／200／201）：未在目標時每 tick 核對 OutArm ZA home 與 Out Y Left；失效停 Out X。
- W906_Ht9050OutSht2ToLeft 的「2」是 M18 出料 Y，不能為了改稱呼去改硬體常數。
- W906_Ht9050OutShtYToRight（OutSH 200）：有料交給 OutArm 前，Out X 須已在 Right 且停止、OutArm ZA 須在原點，才把 M18 Out Y 推到 Prod.OutSHT[1].iRight；等待時不結束本步，條件失效停 Out Y。
- W906_Ht9050OutShtYReadyForPick：DoPickFromShuttle_9045_All_1Pick 在 iSht==0 時等待上述 Out Y Right 到位；這個 helper 只對 Type_HT9050 檢查，其他機型直接放行。Out X 下次進測區前，W906_Ht9050OutSht1MoveBlocked 會讓 Out Y 回 Left。
- W-44 的 Index Z1 下壓前條件依 Steven 20261006 裁決，核對飛梭已離開 socket 區、位於安全區；預設範圍須按各飛梭教點的 sign(Right − Left) 判斷方向，寬度涵蓋 shuttle shake 擺幅。裁決原文、預設公式及實作／生效狀態讀 [Index reference §9](../../ht9045-index-flow/references/ht9050-index-fp-flow.md)，此處不以 Shuttle guard 代替 Index 端核對。
