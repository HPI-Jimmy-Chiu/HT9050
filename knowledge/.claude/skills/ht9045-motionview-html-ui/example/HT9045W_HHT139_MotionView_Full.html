Pitch 模式 寫死「固定間距、必須連續」，所以尾欄只能單支； Fixed 對照組也還是「一次多支、只鎖定一個間距」 依實機設定用 Open/Close：每一針重新選間距、中間允許空格 （X 可選 2× 或 3× 盤距；Y 變距機型另可選 2×~6×）。
Fixed 改為真正的 One by one：一次只吸一顆。 依據 AdjustInArmClosePitchCondition()： bVariModeFIX==true → bCanPick2ICAtOnceTime=false → GetInArmToLoaderPosition_Single() 會把其餘吸嘴（含另一排）全部關掉
HotPlate 取料順序 列號升序 → 永遠在前幾排循環，後半段的料一直留在盤上沒被取（soak 過頭） 改為 FIFO：先放先取（取 soak 最久的那一組）。 另補上 site↔吸嘴的對應約束：上排必須是 Site 1~4、下排必須是 Site 5~8 （否則放進 Kit 會撞同一個 Site 槽位）
HotPlate 用滿 只用到 112/128 格，列 14、15 從未使用 滿手一定兩排一起放：分拆放下去會變成單排 4 顆一個 team， 而吸嘴兩排固定差 3 列 → 之後永遠湊不回 8 顆一起取。 代價是 16 列裡有 2 列（第 14、15 列）用不到，可用容量 112/128
