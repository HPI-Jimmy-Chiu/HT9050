# HT9050／PCI-1203 Home

## 差異

HT9050原實機以DS402驅動器做home；SGDX伺服與SW3D步進在原點起跑、速度及完成位置不同。控制卡／driver分類在同一主題的 [driver樹](../drivers/index.md)。

## 入口與流程

- [1203完整原文](../drivers/pci1203/original-entry.md)：全機、單軸、Light Scale route、drive識別、step leave、READYDONE、速度與雙軸。
- [當前共同與差異](../common.md)：查證V906 live MotorHome、RouteHomeDone與默認ZSafe旗標。

## 安全

原點極性與HomeDirection、已停止、新樣本、安全門、驅動器profile／offset及mot table Enable需核對。新drive完成位置未確認時，不能泛用cmd==0。機台側歷史臨時bypass並不是main的通用知識；來源與解除條件保留，不因此更改設定或動馬達。
