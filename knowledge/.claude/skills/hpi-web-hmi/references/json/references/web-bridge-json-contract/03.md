## 一個貫穿全文的原則

> **不可知就送 `null`，不要送 0、不要送空字串、不要送 DFM 的展示值。**

`WebBridge/TagSnapshot.h` section 4 rule 3 已經這樣定，HTML 端也照這個實作（`null` 一律顯示 `---`）。
理由很實際：`0` 是合法的溫度、合法的計數、合法的權限等級。把「還沒讀到」顯示成 `0`，
操作員會照著一個編造的數字做決定，而且畫面看起來完全正常。
