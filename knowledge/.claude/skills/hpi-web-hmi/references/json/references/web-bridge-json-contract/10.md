## 2.3 `snapshot` 要能主動重送

**要求**：指令 `stream.resync`，ack 之後（或同時）送一幀完整 `snapshot`。

**為什麼**：目前 `snapshot` **只在連線建立時送一次**（`WebBridgeServer.cpp:1125`）。
HTML 發現 seq 跳號時，唯一的補救方法是斷線重連 —— 那會連帶丟掉單一操作員權杖，
如果當下正在寫入流程中間，後果不可控。
