# UPH 共用讀法

## 本批已核對的共同點

HT9045 repo 與入口網站的 **HT9050 離線計算頁**，`calc(d,p)` 都先呼叫
`paths()`、`schedule()`，以 `P = max(sc.P, 0.001)` 計算 `3600 / P × p.pYield / 100`。
這是兩份頁面相同的計算口徑；不能推論其他機型的 C++ 都走同一實作。
來源及函式定位：[HTML 來源](resources.md#html-來源)。

## 讀任何機型前要定義的量

| 量 | 要確認的口徑 |
|---|---|
| 時間 | 秒、暖機／穩態、是否含暫停、換盤、失敗重試 |
| 每批顆數 | 單顆、吸取次數、啟用 site、實際 good units，不能自行互換 |
| 良率 | 是否已在計數扣除；避免再乘一次 |
| 週期 | 排程起始間隔、單顆動畫總長、每盤耗時，各自保留名稱 |
| 容量與機構 | 實際 HP／Tray 可用格數、單／雙 Index、吸嘴配置 |

[機型路由](machines/index.md) 決定模型；未核對的機型先讀實際分派，不能從相同變數名抽共同流程。
