## 9. 推送後的通知信（UPH Simulator → GitLab → Maurice）

> **//Steven 20260923** 新增。UPH 模擬頁改完、push 到 `9050motionview` 之後，**一定要寄一封通知信**。
> 這是使用者 20260923 的指示，授權直接寄出，不必先開草稿等確認。

### 9.1 收件人與主旨

| | |
|---|---|
| 收件者 | `Maurice@honprec.com` |
| 副本 | `steven@honprec.com`（寄件備份之一） |
| 主旨 | `[HT9xxx UPH Simulator Gitlab Commit] <分支> -> <新 HEAD>：<三到五個重點>` |
| 附件 | **不放**。頁面在 GitLab Pages，信裡給網址就好 |
| 格式 | **純文字**（`BodyFormat = 1`） |

主旨標籤沿用 [[mail-subject-convention]] 的規則（方括號標籤開頭），
標籤字面即使用者指定的 `HT9xxx UPH Simulator Gitlab Commit`。

### 9.2 內文順序（收件人先看到「我要做什麼」）

1. **怎麼看**：GitLab Pages 網址（入口 ＋ 兩支 UPH 頁）、結尾斜線要保留、
   `pages.honprec.com` 免登入而 `gitlab.honprec.com` 需登入、
   `?lang=en` 可直接給外籍同事或客戶、clone 後雙擊 `public\index.html` 也能開。
2. **這次推了什麼**：分支與 commit 範圍，每顆 commit 一行，再逐項說明功能與代表性數字。
3. **已知待補**：把還沒確認的假設講清楚（例如 NN mode 的 index time、HT9050 的加熱盤位數與 soak），
   並說明那些數字「先當趨勢看」。
4. **備註**：預設秒數是示意值、實際產能以機台 Per-Tray UPH（`CalculateUPH`）為準。

用字依 [[reports-use-names-not-pronouns]]：跨人信件寫名字（Steven / Maurice），不用你我他。

### 9.3 寄法：Outlook COM（這台機器沒有 email 工具）

```powershell
$body = Get-Content -Raw -Encoding UTF8 '<信稿.txt>'      # 內文先寫成 UTF-8 檔再讀進來
$ol   = [Runtime.InteropServices.Marshal]::GetActiveObject('Outlook.Application')
$mail = $ol.CreateItem(0)
$mail.To         = 'Maurice@honprec.com'
$mail.CC         = 'steven@honprec.com'
$mail.Subject    = '[HT9xxx UPH Simulator Gitlab Commit] main -> 72a80e1：...'
$mail.BodyFormat = 1
$mail.Body       = $body
$mail.DeleteAfterSubmit = $false
$mail.Send()
```

### 9.4 寄完一定要驗（三個數字）

```powershell
$ns = $ol.GetNamespace('MAPI')
$ns.GetDefaultFolder(5).Items  | ? { $_.Subject -like '*UPH Simulator*' }        # 寄件備份匣：要找得到
($ns.GetDefaultFolder(16).Items | ? { $_.Subject -like '*UPH Simulator*' }).Count # 草稿匣：要 0
($ns.GetDefaultFolder(4).Items).Count                                            # 寄件匣 Outbox：要 0
```

`Send()` 沒報錯**不等於**信出去了 —— 卡在 Outbox 也是安靜的。三個數字都對才算寄出。
完整做法與更多坑（信稿換行、附件政策）見 skill `ht9045-html-mirror-backup`。
