## 3. 實戰案例總結

在 2026-03-27 的 Hangup 個案中，這套讀法幫助快速排除兩種常見誤判：

- 誤判 InArm 卡死
- 誤判 Shuttle 單純無法左移

正確做法是：

1. 先從 `InArmSuck` 證明 InArm 手上有料，且其等待 Shuttle 回左屬正常語意。
2. 再從 `FRCarryKit` / `BRCarryKit` 與 `OutArmSuck` 的對照，判定後續應優先查 OutArm 是否未成功把 Shuttle 上的料搬走。
