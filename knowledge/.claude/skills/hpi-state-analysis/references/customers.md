# 客戶、recipe與案例

CUSTOMER_CODE、功能旗標與客戶名稱分開；以記錄包的作用中版本／recipe／config決定需要查哪條Task／case。資料權威與碼別名見[客戶索引](../../hpi-customer-features/SKILL.md)，設定分流見[Config](../../hpi-config/SKILL.md)。

本次沒有新增人工客戶功能表或改他人的條件結論。原OCR／Barcode與MultiZone案例保留客戶、日期、版本和證據，見[案例](cases/index.md)；不能由客戶名猜代理商、語言、HT9050預設碼或根因。

ATC／測試模式、開關、到位／等待與安全互鎖需讀所屬主題；狀態記錄的分析證據不等於變更runtime或執行機台動作的授權。
