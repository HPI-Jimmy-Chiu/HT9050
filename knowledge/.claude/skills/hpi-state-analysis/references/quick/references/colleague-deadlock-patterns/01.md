## 快速比對指南

收到 StateRecord 後，按以下順序比對：

1. **先看 Task 最終狀態組合**（查下方各 Pattern 的「識別特徵」）
2. **再看 EventLog** 是否有匹配的 ALARM 序列
3. **最後確認 Config 旗標**

命中任一 Pattern → 直接引用結論 + 修正建議，標記「已知模式 Pattern #N」。

> 此文件為累積式文件。每次新案例確認後，以遞增編號新增 Pattern。
