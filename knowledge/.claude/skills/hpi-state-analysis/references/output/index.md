# 輸出模板與快速摘要

讀[原data-analysis](../quick/original-entry.md)的固定輸出：問題摘要、關鍵證據、前三個根因假設、各自最短驗證步驟及修正建議；資料不足時寫缺口與影響，不填猜測。

主迴圈健康同時列MainProc的LastEnter、SaveTime、差值、Task_ListWithTime2最後正常時間、正常／可疑／疑似停擺分類及信心理由，見[完整SOP](../source/references/analysis-sop.md)。報告可用CSV資料列／時間定位證據，程式來源則用版本／function／變數，不用程式行號作主要參照。

對使用者與現場的說明用繁體中文，先寫結論與證據，再寫未確定的假設。保留原同事模板與日期；快速摘要不取代完整版本／runtime核對。
