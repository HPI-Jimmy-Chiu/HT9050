## 版面拖曳模式（2026-08-26）

- 入口：Debug ▾ →「🧲 版面拖曳模式」（#smiLayoutEdit，`data-noalert` 跳過 generic alert）→ main 發 `{layoutEdit:1}` → background `layoutMode(true)`：顯示頂層控制列 `#layoutBar`（**fixed top:80 right:8 直式排列 z9999**，標題兩行「🧲 拖拉移位／點選元件開屬性盤」：➕ 元件盤／💾 存檔並結束／↩ 放棄本次變更／📤 匯出 JSON）＋廣播 `HT_LAYOUT_EDIT{on}`。`#compPalette` 元件盤開啟時位在控制列左側（right:158）直式排列，兩盤皆可拖標題移動（移動時清 right 改用 left）。
- 拖曳邏輯在 theme.js（全頁面共用）：編輯中 body.layoutEdit（cursor:move、hover 桃紅虛線 .hlDrag）、capture 階段攔截 click 防觸發原功能；`pick()`=closest('[title],img,button,input,select,label')。
- 拖放以 `transform:translate` 偏移，即時存 `localStorage('ht9xxx-layout')`＝`{頁面key(page/…):{選擇器:[dx,dy]}}`（id 優先，否則 body> nth-child 路徑）；各頁載入時 `applyLayout()` 自動套用。
- 存檔=僅離開模式（已即時存）；放棄=還原進入時快照並清 transform 重套；匯出=下載 ht9xxx-layout.json（格式 `{offsets, adds, props, groups}` 四鍵）。控制列在 background 頂層故不受 iframe 點擊攞截影響。
- **新增元件（➕ 元件盤）**：控制列 `#lbAdd` 開 `#compPalette`（11 種：label/button/edit/checkbox/select/panel/led/labeledled/btnpanel/speedbtn/tray）。**主要流程＝點選放置**（file:// 跨 iframe 的 HTML5 拖放被瀏覽器安全機制擋掉，drop 不觸發）：點 `.cpi` 選取（桃紅 `.sel`，再點取消）→ background `broadcastAll({type:'HT_LAYOUT_PLACE',ctype})` → theme.js 設 `placeType`＋`body.layoutPlace` 十字游標 → 使用者到視窗內點一下 → click capture 呼叫 `placeComp(type,pageX,pageY)`：`prompt` 元件命名（作為 id，重複自動加 `_2`）→ 部分型別再 prompt 顯示文字（select 用 `|` 分隔選項）→ `makeComp()` 建立（led/btnpanel/tray 優先用 HTWidgets，無則退回簡易 div）→ `postMessage({compPlaced:1})` 回 background `clearPlaceSel()` 清選取並廣播 ctype:null。dragstart/drop（`text/plain='HTCOMP:<type>'`）保留為備用路徑。持久化 `localStorage('ht9xxx-layout-add')`＝`{頁面key:[{name,type,x,y,text}]}`，載入時 `applyAdds()` 重建（先 adds 再 offsets，自訂元件也可再拖曳調位）。編輯中**右鍵**自訂元件（`[data-htadd]`）→ confirm 刪除（同時清其偏移）。放棄快照含 adds（snap2）。
- 注意：偏移用 transform，若元件本身已有 transform 會被覆蓋。
- **屬性盤（🛠）**：編輯模式下**點選**任一元件（pick 命中）→ theme.js 在頁內右上角顯示 `#htPropPanel`（fixed z100000，選取元件藍框 `.hlSel`），可調：文字（TreeWalker 改最後非空文字節點，兼容 checkbox/lledf；INPUT 改 value）、字級、文字色／底色（color input，✕ 清除）、寬／高、偏移 X/Y（寫回 offsets 存儲，與拖拉同步）、隱藏（編輯中 opacity .3 可選、離開後 visibility:hidden）；欄位清空即回復原狀（ORIG 快照：先還原 style 再套用）。持久化 `localStorage('ht9xxx-layout-prop')`＝`{頁面key:{選擇器:{text,fs,color,bg,w,h,hide}}}`，載入時 `applyProps()`（順序 adds→offsets→props）；「還原屬性」清該元件全部屬性、「刪除」僅自訂元件（delAdd 同時清 offsets/props）；放棄快照含 props（snap3）並由 ORIG 還原 style/文字。面板內部事件全部排除於 pick/拖拉/click 攞截之外。放置新元件後自動開屬性盤。**名稱欄（.ppName）**：自訂元件（data-htadd）可改名——`renameAdd()` 改 adds rec.name／el.id／data-htadd／title，並遷移 offsets/props/ORIG/moved 的 `#舊名→#新名` 鍵（id 重複時 alert 拒絕）；dfm 元件名稱唯讀（HTML 重生成後 id 固定，改名無法持久）。**屬性盤定位**：showPanel 末端依選取元件 getBoundingClientRect 定位——優先元件右側+10px、放不下改左側、再夾限可視區（清 right/bottom 改用 left/top）。
- **群組（2026-08-27）**：編輯模式 **Ctrl+點選** 多選元件（綠虛框 `.hlMulti`，msel[]）→ 開任一元件屬性盤按「群組」（成員=msel∪目前選取，≥2 才建立；成員自動先脫離舊群組）。選取群組成員時 `.ppGrpInfo` 顯「×N 成員」＋其他成員橘點框 `.hlGrpM`、「解群組」鈕出現；**拖曳任一成員=全員連動**（mousedown 時 `groupOf(sel)` 建 grpDrag 清單，mouseup 各自存偏移；panel 開啟時回寫 ppX/ppY）。持久化 `localStorage('ht9xxx-layout-group')`＝`{頁面key:[[sel,…],…]}`（KEY4）；刪除/改名自訂元件連動群組清單；放棄快照含 groups（snap4）；hidePanel/exitMode 清 .hlGrpM/msel/grpDrag。
- **型別分流屬性盤（2026-08-27 Set 23）**：`compType(el)`＝adds rec.type 優先，否則 title 正則判型——**labeledled 正則必須排在 led 之前**（dfm `.lled` 包裝 title 同時含 TMyLabeledLedLane 與 TMyLedLane，順序錯會誤判成 led）。分流規則：`led`→隱藏文字列（.ppRowText）；`labeledled`→顯示「文字位」select（.ppRowPos，lpLeft/lpRight/lpTop/lpBottom；自訂元件可改、dfm 元件 disabled 並從 title `CaptionPos=` 讀現值）；`tray`→顯示「格數」Row×Col（.ppRowTray，Row=YItem／Col=XItem，min1 max60；自訂可改、dfm disabled）。自訂元件改文字位/格數走 `rebuildAdd(el,mut)`：saveAdds→el.remove()→makeComp 重建→還原偏移＋`delete ORIG[sk]`（**必須清舊 ORIG，否則舊元件 style 快照污染新 DOM**）→applyProp→showPanel。
- **拖拉縮放把手（2026-08-27 Set 23）**：compType ∈ groupbox/panel/tray 時選取元件右下角顯示 `#htRszHandle`（14×14 藍方塊 fixed z100001，body.layoutEdit 下 cursor:nwse-resize——CSS 需 `body.layoutEdit #htRszHandle` 高 specificity 蓋過 `body.layoutEdit *{cursor:move}`）。把手 mousedown（capture）記 rszDrag={x,y,w,h}→document mousemove 即時改 selEl width/height＋posRsz()→mouseup `setField('w'/'h')` 寫入 props 並回寫 ppW/ppH。**陷阱**：document 的 mousedown/mousemove/click 皆 capture 且先於元素 listener → 三處都要 `e.target.id==='htRszHandle'` 早退 guard；pick() 也要排除把手。dfm 元件同樣適用（w/h 屬性本就可存）。元件拖曳中 `if(cur===selEl) posRsz()` 讓把手跟隨；hidePanel/exitMode 收把手＋清 rszDrag。
- **屬性盤小視窗防裁切（2026-08-27）**：showPanel 於 display:block 後、offsetWidth/Height 量測**前**設 `panel.style.maxWidth/maxHeight = 可視區−8`＋`overflowY:auto`——小 iframe 視窗（如 testcat 268×214）面板超高時內部捲動，不會被 iframe 邊界裁掉；後續 pw/ph 夾限計算自動用壓縮後尺寸。
- **基底版面（2026-08-27 Set 33）**：`page/ht9xxx-layout.json`＝使用者匯出的原始 JSON（來源真相），生成 `page/ht9xxx-layout-base.js`（內容 `window.HTLAYOUT_BASE={offsets,adds,props,groups}` compact JSON）。theme.js 的 loadAll/loadAdds/loadProps/loadGroups 改為 `Object.assign({}, baseOf(k), localStorage 同鍵)` **頁鍵層級合併，localStorage 優先**；apply 序列若 `window.HTLAYOUT_BASE` 不存在則動態插入 `<script src='ht9xxx-layout-base.js'>` onload 後才 apply（各頁在 page/ 下相對路徑可解析）。background.html 直接 `<script>` 引入（放 theme.js 之前），且匯出鈕 `mg(bk,lk)` 合併基底＋localStorage 輸出——**匯出永遠含基底**。更新流程：使用者再匯出新 JSON → 覆蓋 .json → 一行 python 重生 base.js。
