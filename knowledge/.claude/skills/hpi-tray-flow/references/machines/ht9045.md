# HT9045 與相關通用 Tray 配置

## 差異

Loader／Empty／Color 在原資料共用三階 helper，但 Loader 另有 UpPress；Auto helper 和 Double-Belt 模式不能完全等同。與 HT9050 對照見 [共同表](../common.md)。

## 安全

原 CatchTray 的 TrayArm↔OutArm 雙向防護、P04路由三個判斷點、CC_SCC退盤不可中途Init、軟硬資料交棒與原版修正紀錄均依章節保留。不要依 Alarm 字面跳過 Task 及 HasTray／sensor 查證。
