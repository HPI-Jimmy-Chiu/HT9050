## 1. 結構概覽

`HT9045_CONFIG` 定義於 `Config.h`，由全域物件 `IniConfig` 存取：

```cpp
extern HT9045_CONFIG IniConfig;

IniConfig.bEnable_SECS_GEM            // 讀取
IniConfig.bA32EnableFTPAutomation = true; // 寫入
```

設定值由 `cConfiguration.cpp` 初始化，並透過 `HTEditList` 與 UI 元件雙向綁定。
