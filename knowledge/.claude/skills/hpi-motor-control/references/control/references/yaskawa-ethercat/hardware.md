# 硬體：型號解碼、馬達規格、煞車／編碼器選項、線材

> 來源：型錄 KAEP03（YAI-KAEPC71081203）、02H（SIEP C710812 02H）、12K（SIEP C710812 12K）；頁碼都是 PDF 頁碼。
> HT9050 實際用了哪些型號以 [motors-9050.md](../../../../../ht9050-hw/references/motors-9050.md)（硬體表）為準；本檔只負責「型號怎麼讀」與「規格去哪裡查」。

## 2. 馬達型號（SGMXJ／SGMXA／SGMXP／SGMXG）

格式：`SGMXJ-01AUA21A1`（KAEP03 p.41，圖面判讀）。

| 位數 | 意義 | 代碼 |
|---|---|---|
| 1-2 | 額定輸出 | SGMXJ：A5＝50 W、01＝100 W、C2＝150 W、02＝200 W、04＝400 W、06＝600 W、08＝750 W；SGMXA 另有 10＝1.0 kW、15＝1.5、20＝2.0、25＝2.5、**30＝3.0**、40＝4.0、50＝5.0、70＝7.0 kW |
| 3 | 電源電壓 | A＝200 VAC（SGMXA 另有 D＝400 VAC） |
| 4 | 串列編碼器 | **U＝26 位元絕對編碼器**、**W＝26 位元無電池絕對編碼器** |
| 5 | 設計版次 | A |
| 6 | 軸端 | 2＝直軸無鍵；**6＝直軸附鍵與螺孔**；B＝雙平面（SGMXJ／SGMXA） |
| 7 | 選項 | **1＝無**；**C＝附保持煞車（24 VDC）**；E＝油封＋煞車；S＝油封（SGMXA-70A 沒有煞車款） |
| 8 | 出貨地 | A |
| 9 | 附屬規格 | 1＝標準；**2＝Σ-7 相容**；3＝標準 Safety；4＝Σ-7 相容 Safety |

| 型號 | 解讀 |

| SGMXJ-08AUA61A2 | 750 W、200 V、**U 編碼器**、直軸附鍵、無煞車、Σ-7 相容 |

| SGMXJ-02AUA6CA2 | 200 W、U、**附煞車**、Σ-7 相容（M3、M22） |

- 型錄值是繞組 100°C（SGMXJ、SGMXA-A5～-10）或 20°C（SGMXA-15～-70）時的典型值；額定扭力是周圍 40°C、裝指定散熱片時的連續容許值（KAEP03 p.59、p.80）。
- 煞車：不能拿來煞停；放開／作用時間依放電電路而變，要在實機確認；24 VDC 電源安川不提供（KAEP03 p.59、p.81）。02H p.206 的延遲表與型錄一致。
- 軟體端要額定扭力時直接讀 6076h（mN·m，02H p.686）；6072h 開機時自動設成馬達最大扭力（02H p.688）。
- 驅動器本身的額定／過載特性：02H p.72-76（Ratings、Overload Protection）；外形 p.89-99；降額 p.112。

## 4. 編碼器、電池

- U／W 都是 26 位元＝67108864 inc/rev（02H p.215）。
- 電池接法：用附電池盒的編碼器線（JUSP-BA01-E），**或**電池裝在主站側——**不能兩邊都裝**（02H p.148、p.266；12K p.61）。
  用無電池型編碼器線的情況：電池裝在主站側、或把絕對編碼器當增量用（12K p.45、p.61）。
- 電池約 2.7 V 以下報 A.830／A.930；不通電標準壽命 3 年（02H p.699）。剩餘電量／電壓可讀 2771h:5（Un17B）、2771h:16（Un178）（02H p.661）。

| 超過 20 m | 中繼線＋兩端接頭線（＋電池盒中繼線） | 12K p.45-46、p.78 |

- 長度代碼：□□ 換成 03、05、10、15、20（m）（12K p.60-61）。耐彎曲線建議彎曲半徑 ≥ 46 mm，機器人等可動部用耐彎曲線（12K p.60）。
- 主迴路線、煞車線依「有無煞車」分不同型號；線材方向（負載側／非負載側）不同型號不同，訂之前先確認（12K p.45）。SGMXA-15～-70 的主迴路／煞車接頭自製方法見 12K p.96-103。
- 02H 端：煞車要用獨立 24 V 電源、突波吸收器裝在馬達煞車端子附近（02H p.156）。CN1 的 I/O 線、CN8 安全功能線見 12K §11.4-11.5（p.387-398）。
