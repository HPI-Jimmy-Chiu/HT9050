## TS 開關狀態位元

`TS` 命令回傳的狀態位元定義：

| 位元 | 說明 |
|------|------|
| 0 | Home 感測器 (active low) |
| 1 | Reverse Limit Switch |
| 2 | Forward Limit Switch |
| 3 | 第二 Home |
| 4 | Latch 輸入 |
| 5 | 運動中 |
| 6 | 錯誤 |
| 7 | 運動完成 |

### 範例

```cpp
long status = MOT[MTestY1].Gali_Command("TSW", "ReadStatus");
bool homeOn = (status & 0x01) == 0;   // Home 感測器（低電平有效）
bool moving = (status & 0x20) != 0;   // 運動中
```
