### 四軸同動命令範例

```cpp
// 設定線性補間模式
Gali_Command("LM WXYZ", "Setup");

// 設定向量速度
Gali_Command("VS 10000", "SetVectorSpeed");

// 發送補間增量（W, X, Y, Z）
Gali_Command("LI 0,0,1000,-1000", "MoveZ1UpZ2Down");

// 結束補間
Gali_Command("LE", "EndInterpolation");

// 開始運動
Gali_Command("BGS", "StartVector");
```
