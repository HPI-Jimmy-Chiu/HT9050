## Operand 使用摘要

Galil 控制器支援以 `_` 開頭的 Operand 語法，可直接在表達式中使用：

```
' 讀取狀態
IF (_BGA = 1)          ; A 軸運動中
IF (_MOA = 1)          ; A 軸馬達 OFF
Bob = _SCA             ; 讀取停止碼存入變數

' 讀取位置
CurrentPos = _TPA      ; 讀取命令位置
DualPos = _TDA         ; 讀取輔助編碼器
Speed = _SPA           ; 讀取速度設定
```
