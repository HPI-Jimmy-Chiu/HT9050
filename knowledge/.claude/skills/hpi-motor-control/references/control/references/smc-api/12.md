## 注意事項

1. **軸號對應**：手冊中 Axis0~Axis3 對應 API 中 Axis No.1~No.4
2. **脈波輸出格式**：需透過硬體開關（SW）設定 Open-Collector 或差動輸出
3. **終端電阻**：差動輸入需啟用終端電阻（透過 DIP 開關設定）
4. **Board ID**：多卡使用時需設定不同 ID（0~F，透過旋鈕開關）
5. **Frame 執行**：支援迴圈執行（Loop Operation）
