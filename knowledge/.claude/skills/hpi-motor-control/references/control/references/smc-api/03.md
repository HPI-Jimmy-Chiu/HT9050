## 主要功能

- **PTP 定位運動**：點到點定位移動
- **JOG 運動**：連續移動操作
- **ORG 原點復歸**：原點搜尋功能
- **線性補間**：多軸直線插補
- **圓弧補間**：圓弧插補
- **S 曲線加減速**：平滑加減速控制
- **Frame 序列運動**：最多 1024 個 frame 連續執行
- **同步控制**：多軸/多卡同步啟動/停止
