## 硬體規格摘要

| 項目 | 規格 |
|------|------|
| 介面 | PCI Bus |
| 脈波輸出 | 6.5Mpps（每軸） |
| 脈波格式 | 單脈波/雙脈波/90° 相差 |
| 輸出格式 | 差動/Open-Collector 可切換 |
| 編碼器輸入 | 差動/TTL/Open-Collector |
| 極限輸入 | 每軸 3 點（+LIM, -LIM, ORG） |
| 通用輸入 | 每軸 7 點 |
| 通用輸出 | 每軸 3 點 |
| 補間功能 | 線性/圓弧 |
| Frame 儲存 | 1024 frames/軸 |
| 同步控制 | 最多 16 卡（128 軸） |
