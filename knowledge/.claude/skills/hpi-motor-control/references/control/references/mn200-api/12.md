## 類比 I/O 函式

### mn_set_ao

```cpp
short mn_set_ao(BYTE bLineNo, BYTE bDevNo, BYTE bChannelNo, float fData);
```

**功能**：設定類比輸出（-10V ~ +10V）

### mn_get_ai

```cpp
short mn_get_ai(BYTE bLineNo, BYTE bDevNo, BYTE bChannelNo, float* pData);
```

**功能**：讀取類比輸入

### mn_get_ai_all

```cpp
short mn_get_ai_all(BYTE bLineNo, BYTE bDevNo, float fData[]);
```

**功能**：讀取所有類比輸入通道
