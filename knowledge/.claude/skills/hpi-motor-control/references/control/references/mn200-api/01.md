## 系統架構

### 通訊線拓撲

```
PISO-MN200 (主卡)
    │
    ├── Line 0 ─┬── Dev 0  (軸 0)
    │           ├── Dev 1  (軸 1)
    │           ├── ...
    │           └── Dev 63 (軸 63)
    │
    └── Line 1 ─┬── Dev 0
                └── ...
```

### 全域變數（HT9045 使用）

```cpp
BYTE NumLine;                    // 通訊線數量
DWORD MN_200_ErrorTable[4];      // 錯誤表
bool bResetMNet;                 // 重置旗標
SPEED_PAR MN200SpeedPar;         // 速度參數結構
```
