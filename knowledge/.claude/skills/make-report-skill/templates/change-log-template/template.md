## 0. 怎麼在程式碼裡找到這些修改

所有當日手動修改的地方都加了統一標頭：

```
//{作者} {YYYYMMDD}          C/C++、JavaScript
# {作者} {YYYYMMDD}          Python
<!-- {作者} {YYYYMMDD} -->   HTML
```

全樹搜尋這個字串就能列出所有改動點：

```
grep -rn "{作者} {YYYYMMDD}" {專案根目錄} --include=*.cpp --include=*.h --include=*.js --include=*.py --include=*.html
```

{若專案本身另有既有的 AI 標記慣例（例：`//AI(AgentName) YYYYMMDD: 描述`），
在此列出對照表，並說明兩者並存、互不取代。}
