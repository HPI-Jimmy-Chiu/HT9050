## 與 TLaneIO 整合

在 HT9045 專案中，`TLaneIO` 會根據 `ISABase` 類型選擇適當的 API：

| ISABase | 供應商 | API 前綴 |
|---------|--------|----------|
| `eMotionNet` (0) | SYN-TEK 或 ICP-DAS | `_mnet_` 或 `mn_` |

詳見 [io-classes.md](../io-classes.md) 中 `TLaneIO` 類別說明。
