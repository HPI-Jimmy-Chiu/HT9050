## 系統架構

```
┌──────────────────────────────────────────────────────────┐
│                       PISO-MN200                          │
│                    (PCI 介面卡)                           │
│                                                           │
│   ┌───────────────┐           ┌───────────────┐          │
│   │   Line 0      │           │   Line 1      │          │
│   │  (Card ID×2)  │           │ (Card ID×2+1) │          │
│   └───────┬───────┘           └───────┬───────┘          │
└───────────┼───────────────────────────┼──────────────────┘
            │                           │
            ▼                           ▼
     ┌──────────────────────────────────────────────┐
     │              Motionnet Bus                    │
     │  ┌─────┐  ┌─────┐  ┌───────┐  ┌───────┐     │
     │  │Servo│→ │Servo│→ │32DI/DO│→ │16DI/DO│→... │
     │  │Dev0 │  │Dev1 │  │  Dev2 │  │  Dev3 │     │
     │  └─────┘  └─────┘  └───────┘  └───────┘     │
     └──────────────────────────────────────────────┘
```

### Card ID 與通訊線編號對應

| Card ID (DIP Switch) | Line 0 | Line 1 |
|---------------------|--------|--------|
| 0 | No.0 | No.1 |
| 1 | No.2 | No.3 |
| 15 | No.30 | No.31 |
