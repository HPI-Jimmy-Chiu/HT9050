## 系統架構

```
┌──────────────────┐
│  Master Card     │
│  (PCI-L132)      │
│                  │
│  ┌─────┐ ┌─────┐ │
│  │Ring0│ │Ring1│ │
│  └──┬──┘ └──┬──┘ │
└─────┼───────┼────┘
      │       │
      │       └──────────────────────────────────────┐
      │                                              │
      ▼                                              ▼
┌─────────┐   ┌─────────┐   ┌─────────┐      ┌─────────┐
│ Slave   │───│ Slave   │───│ Slave   │ ...  │ Slave   │[TR]
│ IP=0    │   │ IP=1    │   │ IP=2    │      │ IP=63   │
└─────────┘   └─────────┘   └─────────┘      └─────────┘
                                              (Terminator)
```

### 通訊類型

| 類型 | 說明 |
|------|------|
| Cyclic Data | DIO Slave 使用，週期性資料交換 |
| Wrapped Data | Motion Slave 使用，封包式資料交換 |
