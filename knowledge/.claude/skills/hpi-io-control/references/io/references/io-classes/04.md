## TMySensor

**標頭檔**: `mysensor.h`  
**原始檔**: `mysensor.cpp`  
**全域陣列**: `Sen[MAX_SENSOR_ITEM]`

### 成員

| 成員 | 型別 | 說明 |
|------|------|------|
| `Name` | AnsiString | 感測器名稱 |
| `Enable` | bool | 感測器啟用 |
| `Ring` | int | MotionNet Ring |
| `IP` | int | MotionNet IP |
| `Port` | int | Port 編號 |
| `Bit` | int | Bit 編號 |
| `Type` | int | 0=低電位有效, 1=高電位有效 |
| `ISABase` | int | IO 基底類型 |
| `State` | int | 上次讀取狀態 |
| `Using` | AnsiString | 使用說明 |

### 方法

| 方法 | 回傳 | 說明 |
|------|------|------|
| `Status()` | bool | 讀取感測器（依 Type 判斷） |
| `IsOn()` | bool | 同 Status() |
| `IsOff()` | bool | Status() 的反向值 |
