## 錯誤碼

### 常見錯誤

| 錯誤碼 | 說明 |
|--------|------|
| 0 | 成功（無錯誤） |
| 1 | 無效設備 Handle |
| 2 | 無效軸 Handle |
| 3 | 無效群組 Handle |
| 4 | 參數超出範圍 |
| 5 | 緩衝區不足 |

### EtherCAT 錯誤

| 錯誤碼 | 說明 |
|--------|------|
| 0x8001 | EtherCAT 通訊錯誤 |
| 0x8002 | 從站未連接 |
| 0x8003 | 從站狀態錯誤 |
| 0x8004 | SDO 通訊超時 |
