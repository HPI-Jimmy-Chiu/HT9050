## 初始化流程

```
Acm_GetAvailableDevs() → 取得可用設備列表
         ↓
Acm_DevOpen() → 開啟設備，取得 DeviceHandle
         ↓
Acm_DevLoadMapFile() → 下載映射檔（可選）
         ↓
Acm_AxOpen() / Acm_GpOpen() → 開啟軸/群組
         ↓
     ... 運動/IO 控制 ...
         ↓
Acm_AxClose() / Acm_GpClose() → 關閉軸/群組
         ↓
Acm_DevClose() → 關閉設備
```
