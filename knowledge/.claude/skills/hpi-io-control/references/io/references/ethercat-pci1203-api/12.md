## 與 TLaneIO 整合

在 HT9045 專案中，PCI-1203 透過 `TLaneIO` 封裝使用。當 `ISABase == ePCI1203` 時：

- 初始化透過 `Acm_DevOpen()` 進行
- DIO 操作透過 `Acm_DaqDi*()` / `Acm_DaqDo*()` 函式
- 關閉透過 `Acm_DevClose()`

詳見 [io-classes.md](../io-classes.md) 中 `TLaneIO` 類別的 `ePCI1203` 相關方法。
