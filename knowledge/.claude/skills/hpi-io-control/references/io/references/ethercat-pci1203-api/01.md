## 系統限制

| 參數 | 限制值 |
|------|--------|
| 最大軸數 | 64（0~63） |
| 群組數 | 6 組，每組最多 8 軸插補 |
| 最大 DI/DO 通道數 | 依從站配置，透過 `FT_DaqDiMaxChan`/`FT_DaqDoMaxChan` 取得 |
| 運動環循環時間 | 250μs（最低） |
| IO 環循環時間 | 200μs |
| 主站模式 | 支援多主站同時使用不同 EtherCAT 端口 |
