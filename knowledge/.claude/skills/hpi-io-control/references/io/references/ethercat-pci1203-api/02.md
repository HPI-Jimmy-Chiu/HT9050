## EtherCAT 架構

```
┌──────────────────────────────────────────────────────────────────┐
│                          PCI Bus                                  │
└──────────────────────────────────────────────────────────────────┘
                              │
          ┌───────────────────┴───────────────────┐
          │         PCI-1203 / PCIE-1203          │
          │    ┌─────────────┬─────────────┐      │
          │    │  Motion     │    I/O      │      │
          │    │  Master     │   Master    │      │
          │    │ (250μs)     │  (200μs)    │      │
          │    └─────────────┴─────────────┘      │
          │        │ EtherCAT     │ EtherCAT      │
          └────────┼──────────────┼───────────────┘
                   ↓              ↓
     ┌─────────────┴──────────────┴──────────────────┐
     │              EtherCAT Ring                     │
     │  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐          │
     │  │Servo│→ │Servo│→ │ I/O │→ │ I/O │→ ...    │
     │  │Drive│  │Drive│  │Module│ │Module│          │
     │  └─────┘  └─────┘  └─────┘  └─────┘          │
     └───────────────────────────────────────────────┘
```

### 特性

- **多主站模式**：運動控制與 I/O 可分離至不同主站
- **分布式時鐘（DC）**：從站間同步抖動 < 1μs
- **拓撲結構**：支援總線形、樹形、環形、星形
- **電纜長度**：兩節點間最大 100m（100BASE-TX）
- **最大從站數**：65,535 台
