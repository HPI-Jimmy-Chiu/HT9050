# 客戶碼、build define與runtime

CUSTOMER_CODE、Model／MachineTypeChoice、INSTALL_／USE_／SOFT_SIMULTE和CMake選項分層核對。客戶功能可能有編譯條件也可能有runtime條件，不能由檔名、機型或一次詞法搜尋判定實際有效功能。

客戶資料與人工／候選查證路由見[客戶主題](../../hpi-customer-features/SKILL.md)，設定權威見[Config](../../hpi-config/SKILL.md)。本次沒有新增客戶功能表，也沒有把未編譯／未link／未知define標成已生效。原script範例與客戶案例按其版本保持，客戶MR／交付規則另依最新專案指示。
