## 6. Shuttle AutoClean 定位

DoShuttle1AutoClean / DoShuttle2AutoClean 控制 Shuttle 左右移動：

| 條件 | 動作 |
|------|------|
| Index 未忙碌 + Shuttle 有 Clean IC | → **RIGHT** (往 Index 方向) |
| Shuttle 空 | → **LEFT** (往 InArm 方向裝料) |
| Index 正在接觸中 | → Lock (`fCanMoveM=false`) |
| 錯誤恢復 | → 慢速回 LEFT |
