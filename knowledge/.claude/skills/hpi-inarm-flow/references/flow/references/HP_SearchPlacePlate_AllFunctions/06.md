## §4 XItem3_2Suck_3Site

**全名**: `SearchPlacePlateXItem3_2Suck_3Site()` (line 2917)  
**每次放料數**: 1~2 顆  
**適用 XDiv**: 3（僅 TriSite1X3 + iModeX≠3）

### 掃描邏輯

**XPitch ≤ iXpitchMaxX3/2 時**（窄 Pitch）:
```
Row-first 掃描: for j(Row) → for i(Col)

```
