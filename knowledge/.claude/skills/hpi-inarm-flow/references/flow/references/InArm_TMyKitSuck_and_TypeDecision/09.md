## 9. Item 狀態碼快查

| 代碼 | 意義 |
|------|------|
| `NULL_IC` | 無 IC（空位） |
| `HAS_NULL_IC` | 感應到有 IC 但資料未知（HAS＋NULL混合） |
| `HAS_IC` | 有 IC，尚未預熱 |
| `HAS_HOT_IC` | 有 IC，預熱已完成（Hot 模式） |
| `HAS_TESTING_IC` | IC 正在測試中（已放到 Socket） |
| `START_TEST` 以上 | IC 已完成測試，數值代表測試結果 |
| `CLEAN_FINISH_IC` | AutoClean 用的 dummy IC 狀態 |
