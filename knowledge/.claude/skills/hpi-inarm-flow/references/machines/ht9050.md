# HT9050 InArm差異

| 與多吸嘴配置的差別 | 適用來源／界線 |
|---|---|
| 單Picker，每支手臂四個吸嘴合吸一顆IC，吸嘴帶rotator | Steven／Jimmy 20261004硬體裁決AR-1；四個實體嘴不等於四顆DUT |
| 教導A吸嘴，間距0；整理提案指出Loader教導為盤參考；不能直接套E／F基準的多吸嘴Pitch公式 | AR-2核對教導A；Loader盤參考為ST01整理提案，本批未逐條重驗座標公式，需追實際參數與函式 |
| In／Out同套真空分組規則；Out接線順序與In相反 | IO名字／分組辨識，不自行翻接線或啟用開關 |
| 入、出飛梭獨立；沒有第二組入料飛梭，M18是出料飛梭Y | 跨主題互鎖查Shuttle；Single Picker通用程式仍可能有MInShuttle2引用，需查分派與配置，不能視為第二台真實飛梭 |
| 只有HP1，沒有HP2 | Frank 20261006 14:4x裁決（RULINGS_20261006 §18）；不要把歷史雙加熱盤範例套到HT9050 |
| 程式入口可沿用9045命名 | main DoInArm_9045依USE_PICKER_COUNT派DoInArm_9045_All_1Pick，不只按MachineTypeChoice判斷 |

## 入口與流程

依 [目前dispatcher](../runtime/current-main.md) 查`USE_PICKER_COUNT`、`iArmTask`與Hot／常溫路線，再查Loader、HotPlate與Shuttle子流程；Hot模式先放熱盤／後取熱盤的優先條件仍取決於實際Task與配置。
