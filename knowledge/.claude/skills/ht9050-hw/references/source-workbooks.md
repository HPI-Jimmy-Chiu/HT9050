## 2. `HP-9050機構類元件代碼-20260922-2-軟體.xls`（軟體視角）

`01_機構資訊` 166 列 × 13 欄 ＋ `工作表1`（31×6，電磁閥連座的 YV／SQ 編號草稿）。

比 `.xlsx` 版多了四欄，這是它存在的理由：

| 欄 | 內容 |
|----|------|
| `輸入線號` | 如 `15000推`、`15020、15021`、`11220開 11221閉` |
| `輸出線號` | 如 `01104收 01105推`；`~` = 沿用上一列 |
| `命名來源` | `軟體既有`(48) / `建議新增`(23) / 留空(93) |
| `命名說明` | 為什麼這樣命名、對應哪一列、相似的既有名字 |

「命名來源」欄經獨立查核**是準的**（見 [io-table-9050 §4](io-table-9050.md#4-命名來源欄哪些是新名字)）。

## 3. `HP-9050機構類元件代碼-20260923-1-電控.xls`（電控視角）

**與軟體版逐格比對，只有 29 列不同，而且全部集中在「輸出線號」一欄。**
差異形式一致：前綴 `01` → `0B`，且第 3、4 碼歸零：

| 軟體版 | 電控版 |
|--------|--------|
| `01104收 01105推` | `0B004收 0B005推` |
| `01302收 01303推` | `0B202收 0B203推` |
| `01300收 01301推` | `0B200收 0B201推` |
| `01100下 01101上` | `0B000下 0B001上` |
| `01110收 01111推` | `0B010收 0B011推` |
| `01116收 01117推` | `0B016收 0B017推` |
| …（共 29 列，全部同一模式） | |

**輸入線號、站別、料號、品名、規格、I/O 點位、安裝位置、命名來源、命名說明——完全相同。**

實務結論：
- 要接線／查輸出位址 → 用 **電控版（20260923）**
- 要查點位命名與命名來源 → 兩版一樣，用哪版都行
- 只差 29 列表示這兩份是同源分叉，**不是兩份獨立資料**；下次硬體送新版時
  先跑 `scripts/dump_hw_workbooks.py` 再 diff，不要用眼睛比
