**取捨**：
- 只寫紀錄、不擋開機：開機一定成功，但操作員不看 op log 就不會知道。可以補一行狀態：開機摘要（`BootSummary`）印「驗表：ERROR n／WARN n」，網頁只顯示這一行數字，不跳視窗。
- ERROR 要不要擋 START（不是擋開機）：例如 T1、T4、T9 一定會出事。建議第一版先不擋，跑一週看誤報，再決定（Jimmy／EastSun）。
- T10 不能列成錯誤：golden 的大陣列本來就有大多數槽沒有表格列，列成錯誤會淹沒真正的問題。
- 規則要依機種開關：T1、T9 只在 HT9050 檢查（`W906_IsHT9050()`，`uhome.cpp:711`）；其他規則各機種都適用，但只寫紀錄，不改行為，所以不違反「其他機種保持 golden」。
