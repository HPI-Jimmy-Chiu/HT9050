資料用途顯示規則

12. TfQwertyKey（myQwertyKeyBoard.cpp・彈出式觸控小鍵盤）

實機以 fQwertyKey->ShowQwertyKey(目標控制項, iFunction, iDP, bCheckRange, min, max)（ShowModal）呼叫。 iFunction 為 N_ 旗標位元 OR（cmydef.cpp），畫面依模式不同：數字類只顯示右側數字鍵盤（窄）；其餘顯示全 QWERTY； 密碼遮罩並隱藏 Current Value；bCheckRange 顯示 Maximum/Minimum 並於 OK 時夾限。

旗標值畫面/行為
N_INTEGER0x0001只有整數 → 數字鍵盤（含 +1/-1…+100/-100、%）
N_DOUBLE0x0002浮點 → 數字鍵盤含小數點（iDP 位）
N_NO_SYMBOL0x0004停用特殊符號鍵
N_PASSWORD0x0008遮罩 *、隱藏 Current Value
N_NO_SPACE0x0010無空白鍵
N_UPPERCASE0x0020大寫優先
N_NO_NUM_PAD0x0040全鍵盤不含右側數字鍵盤（寬 745）
N_PORT / N_IP_ADDR0x0080 / 0x0100通訊埠(0~65535) / IP（含小數點）

HTML 用法：HTQwerty.show(目標元素, flags, {dp, checkRange, min, max})；OK 寫回目標的 value（input）或 textContent，checkRange 時夾限 min~max。實際使用範例：

  • 主畫面 edSoakTime（Soak Time）：N_INTEGER, dp0, range 5~10000（main.cpp:26024）
  • 主畫面 btLogin（登入）：N_NO_SYMBOL|N_NO_SPACE|N_PASSWORD（main.cpp:34957）
  • cBinSel 存檔：N_NO_SYMBOL|N_NO_SPACE|N_PASSWORD（cBinSel.cpp:2988）；數值格：N_INTEGER
  • 溫度設定：N_DOUBLE, dp2, checkRange（main.cpp:26129）
目標欄：
