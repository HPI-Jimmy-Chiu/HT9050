# HTML 視覺設計 — 操作一覽

> 詳細說明在 README（「元件」欄標題列的 ? 圖示）。這一頁只列「怎麼做」。

## 開頁、換頁

| 要做什麼 | 怎麼做 |
|---|---|
| 開一頁 | 方案總管 → 網頁 → 頁面，點一下；或 .html 右鍵「在設計檢視開啟」 |
| 搜尋頁面／元件 | 方案總管標題列的漏斗（或在方案總管按 `Ctrl+F`／`Ctrl+;`）：頁面名稱、元件名稱、型別、畫面上的文字 |
| 在所有頁面找元件（清單式） | `Ctrl+Alt+Shift+O`，或畫面右鍵 |
| 照某個機種顯示（例如 HT9050 的 Above9050 頁籤） | 右鍵「顯示」→「設計檢視的機種…」；預設跟 F5 一樣 |
| 在這一頁找元件 | `Ctrl+Alt+O` |
| 看 HTML 原始碼 | 設計畫面標題列的 `</>` |
| 換成新裝的版本 | 左下角「🔄 設計工具新版…」，或「元件」標題列／設計畫面標題列的 🔄 |

## 選取

| 要做什麼 | 怎麼做 |
|---|---|
| 選一個 | 按一下（元件樹點一下也可以） |
| 多選 | `Ctrl`／`Shift`＋點；或在表單空白處（或表單外）**拖出框** |
| 同一層全選 | `Ctrl+A`（或右鍵「全選」） |
| 同型別全選（所有 TLabel…） | 右鍵「選取同型別（整頁）」／「（同一層）」 |
| 選上一層／下一個 | `Esc`／`Tab` |
| 選被蓋住的元件 | 在那一點按右鍵 →「選取這裡的元件…」：列出滑鼠底下疊著的所有元件（最上面的在前、表單最後），挑一個（Blend 的 Set Current Selection）；或 `Alt`＋點一下一層一層往下 |
| 調前後順序 | 右鍵「順序」→ 移到最上層／上一層／下一層／最下層；多選時整組一起移，彼此的前後不變（一個 Ctrl+Z） |
| 對齊格線、間距（WinForms／BCB6 的格式選單） | 右鍵「對齊與間距」→ 對齊格線／大小對齊格線；水平／垂直間距加大（一格）、縮小、移除（緊靠）——主要選取不動，其他的推開或靠過來 |
| 全部鎖定 | 元件樹標題列的「…」→「全部鎖定」（表單上的元件和它們裡面的都鎖住）；「全部解除鎖定」解開 |
| 選到最裡面那個／一層一層往下選 | `Alt`＋點（再點一次＝下面那一層） |

## 移動、大小

| 要做什麼 | 怎麼做 |
|---|---|
| 移動 | 拖曳（靠近別的元件會出現紅色對齊線、離鄰居 8 px 時藍色間距線；`Alt` 不吸附） |
| 微調 | 方向鍵 1px、`Shift`＋方向鍵 10px |
| 改大小 | 拉 8 個控制點；或 `Ctrl`＋方向鍵（多選時整組一起改） |
| 輸入數字 | 屬性面板的 Left／Top／Width／Height |
| 對齊／同大小 | 多選後右鍵「對齊與間距」（以最後點的為準） |
| 等距排列 | 選 3 個以上 → 右鍵「對齊與間距 → 水平等距／垂直等距」 |
| 放到容器正中間 | 右鍵「對齊與間距 → 在容器中水平置中／垂直置中」（多選＝整組一起） |
| 吸到格線 | 標題列的 `#`（格線大小：設定 `ht9045Designer.gridSize`） |

## 編輯

| 要做什麼 | 怎麼做 |
|---|---|
| 改名稱（id） | 屬性面板最上面的名稱方塊；元件樹上按 `F2`；右鍵「改名稱」 |
| 直接改元件上的文字 | 設計畫面選好按 `F2`，打字，`Enter` 確定／`Esc` 取消 |
| 剪下／複製／貼上／刪除 | `Ctrl+X`／`Ctrl+C`／`Ctrl+V`／`Del`（右鍵最上面四個） |
| 複製一份放到別的地方 | 按住 `Ctrl` 拖曳元件，放開的地方就是複製的那一份（原本的不動；Ctrl＋點一下＝加選） |
| 複製一份、錯開一點 | `Alt`＋方向鍵（1px）；`Shift+Alt`＋方向鍵（10px） |
| 拖到別的 Panel 裡 | 拖到那個 Panel 上，**拖到一半才按住 `Alt`**、放開（放在放開的位置）；從按下就按著 `Alt`＝只是不吸附 |
| 新增元件（清單選） | `Ctrl+N` |
| 取消全部選取 | `Ctrl+Shift+A` |
| 從元件上開始拉框選 | 按住 `Shift` 拖曳（Shift＋點一下＝加選） |
| 藏起／顯示控制點 | `F9`（選取框、名稱標籤、邊距標示一起） |
| 看元件離容器多遠 | 選它：左邊、上邊的細線和數字＝它的 Left／Top（WPF 的邊距標示） |
| 同寬／同高／同大小 | `Ctrl+Shift+1`／`Ctrl+Shift+2`／`Ctrl+Shift+9` |
| 放大／縮小一級、縮放到選取、100% | `Ctrl+=`／`Ctrl+-`、`Ctrl+0`（`Ctrl+9`）、`Ctrl+1`；按住 `Ctrl+空白鍵` 點一下＝在那裡放大（`Ctrl+Alt+空白鍵`＝縮小） |
| 等比例改大小 | 按住 `Shift` 拉角落的控制點 |
| 新增元件（放在指定位置） | 「**工具箱**」點一下 → 到畫面上點一下（或拖一個框＝連大小）；`Esc` 取消 |
| 新增元件（直接加） | 「工具箱」連點兩下，或選好按 `Enter`（同 WPF；放進選取的 Panel／GroupBox，或放在選取元件下面） |
| 放下拿起的工具 | 「工具箱」最上面的「**指標**」（或 `Esc`）；放好一個元件後會自己回到指標 |
| 設計時隱藏／顯示 | `Ctrl+H`／`Shift+Ctrl+H`（選取的元件；在元件樹＝樹上選的列） |
| 設計時鎖定／解鎖 | `Ctrl+L`／`Shift+Ctrl+L`（同上） |
| 畫面背景亮／暗 | 畫面左下工具列「背景」 |
| 放進新 Panel／解除群組 | `Ctrl+G`／`Ctrl+Shift+G` |
| 換上層容器 | 在元件樹上**拖曳**到別的 Panel／GroupBox |
| 前後順序 | `Ctrl+Shift+]` 最上、`Ctrl+]` 上一層、`Ctrl+[` 下一層、`Ctrl+Shift+[` 最下 |
| 復原／重做 | `Ctrl+Z`／`Ctrl+Y`，或標題列 ↶ ↷ |
| 存檔 | `Ctrl+S`（不按就不會寫到磁碟） |

## 屬性面板（`F4`）

| 要做什麼 | 怎麼做 |
|---|---|
| 改文字、字型、顏色、可見… | 「外觀與版面」那一區，改完按 Enter |
| 換成 BCB6 標準色（clRed…） | Font.Color／Color 下面的 16 個色塊，點一下 |
| 好幾個一起改字型／顏色／寬度 | 多選後在「外觀與版面」改（全部一起改，一個 Ctrl+Z 復原） |
| 好幾個接同一個事件函式 | 多選後在「⚡ 事件」那一列打函式名稱＋Enter（空白 Enter／雙擊＝預設名稱）；右鍵「重設（N 個全部）」全部拿掉 |
| 改回 DFM 的值 | 值不一樣的列會標色；點那一列右邊的小方塊（或在那一列按右鍵）→「重設」；多選時＝每一個改回自己的 DFM 值 |
| True／False 的值 | 點勾選框，或雙擊那一格（只切換一次，跟 BCB6 屬性表一樣） |
| 在屬性之間移動 | Tab／Shift+Tab；下拉選單、勾選框、文字欄上 ↑／↓＝上一列／下一列（數值欄的 ↑／↓＝加減）；`Alt+↓` 打開下拉清單 |
| 整個元件改回 DFM（可多選） | 右鍵「版面重設 → 全部改回 DFM」，或差異說明後面的「這個元件全部改回 DFM」 |
| 只改回位置／大小 | 右鍵「版面重設 → 重設位置／重設大小／重設全部版面」 |
| 改 HTML 的 style／屬性 | 「HTML」那一區點一下值（或雙擊）；最下面可以新增樣式 |
| 找某個屬性 | 最上面的搜尋框（空白隔開＝都要有；`Esc` 清掉） |
| 數值加減 | 屬性面板的數值欄按 ↑／↓（1），Shift＋↑／↓（10）；連按只算一個復原步驟 |
| 跳到屬性在 HTML 裡寫的地方 | 屬性面板雙擊屬性名稱（值會選起來，直接打）；或點那一列右邊的小方塊／在那一列按右鍵 →「跳到 HTML 原始碼」 |
| 輸入／取顏色 | Color／Font.Color 色塊旁的輸入框（#rrggbb、clRed，Enter）；▾＝BCB6 的 16 色和「滴管」（點畫面上的一點取色） |
| 一格一格改屬性 | `Tab`＝下一個屬性的值（小方塊、色塊不會停）；`Enter`＝寫入、游標留著（值選好，直接打下一個）；`Esc`＝放棄這次輸入 |
| 屬性換排列 | 搜尋框旁邊的 類別（預設）／名稱／DFM |
| 收合／展開一類屬性 | 點類別標題（▾ 版面…），或在標題上按 `Enter` |
| 看屬性是什麼意思 | 滑鼠停在屬性名稱上 |
| 放一顆 IO 燈／IO 按鈕 | 工具箱的 MyLedLane／MyLed／ALed／BtnPanelLane／BtnPanel，放好後在 Alias 挑 IO 名稱 |
| 改 IO 燈／按鈕的形狀、亮、按下、顏色 | 選它 → 屬性表「IO 元件」那一類（LEDStyle、Value、Style、Down、TrueColor…） |
| 跳到事件程式 | 雙擊事件＝直接到會執行的那個 C++ 函式；右鍵＝所有找到的程式碼；在畫面上雙擊元件＝它的預設事件（空的＝新增）；`F7`＝只開不新增 |
| 縮放、格線、對齊線 | 設計畫面左下角的工具列（－／比例／＋、全部、選取、格線＝顯示、吸附＝對齊格線、對齊線、背景）；Ctrl＋滾輪也可以縮放（設定 `ht9045Designer.zoomWheel` 可以改成只用滾輪、或 Alt＋滾輪）；重開頁面回到上次的比例（設定 `ht9045Designer.defaultZoom`：上次／符合全部／100%） |
| 選上層 | 屬性面板上方的路徑點一個上層；或 `Esc` |
| 設計畫面 ↔ 程式碼（WPF 的 Shift+F7） | 設計畫面按 `Shift+F7`＝選取元件的 HTML；HTML 或 C++ 裡按 `Shift+F7`＝回到設計畫面、選取游標那個元件 |
| 每次開頁面都並排 HTML（WPF 的 Split） | 設定 `ht9045Designer.defaultView`＝`split` |
| 新增事件（WPF 的事件分頁） | 那一格打名稱＋Enter、雙擊那一格、或空白按 Enter（預設名稱）；下拉＝用已經有的函式；右鍵「重設」或清掉＋Enter＝拿掉連線 |
| 跳到 DFM 定義 | 屬性面板分頁那一行的「DFM」；DFM 屬性雙擊＝那一行；可以改的那些：那一列右邊的小方塊 →「跳到 .dfm」 |

## 顯示

| 要做什麼 | 怎麼做 |
|---|---|
| 縮放 | `Ctrl`＋滾輪（以滑鼠位置為中心）；標題列「符合視窗」；右鍵「顯示 → 縮放回 100%」 |
| 放大看選取的元件 | 右鍵「顯示 → 縮放到選取的元件」 |
| 平移畫面 | 按住**空白鍵**拖曳，或按住滑鼠**中鍵**拖曳 |
| 暫時藏起來（點得穿） | 元件樹的眼睛 |
| 鎖住不讓移動 | 元件樹的鎖頭 |
| 看所有元件名稱 | 右鍵「顯示 → 顯示所有元件名稱」 |
| 看哪些還沒接 | 右鍵「顯示 → 在畫面上標出接線狀態」（綠＝接了、橘＝部分、紅＝沒接） |
| 操作模式（讓頁面自己的點擊動作跑） | 狀態列「設計模式」或標題列鉛筆切換。操作模式**不改原始碼**：右鍵是頁面自己的選單，Delete／Ctrl+G 不刪不群組；用眼睛隱藏的元件照常顯示；網路仍然全部封鎖 |

## 檢查、比對

| 要做什麼 | 怎麼做 |
|---|---|
| 跟 DFM 比對整頁 | 標題列／右鍵「檢查與比對 → 與 DFM 的差異」 |

| 找 HTML 的毛病 | 右鍵「檢查與比對 → 檢查這一頁」／命令選擇區「HTML設計: 檢查所有頁面」→「問題」面板，燈泡修正 |

## CSV 表格（打開 .csv）

| 要做什麼 | 怎麼做 |
|---|---|
| 編輯一格 | 點一下直接打字（中文輸入法也可以），或雙擊（游標停在點的位置）／F2（游標在最後）；Enter 確定並往下，Tab 往右，Esc 取消 |
| 打字中 | 直接打的：方向鍵＝寫入並移動；F2 進去的：方向鍵在格子裡移游標；F2 切換兩種 |
| 選一塊 | Shift＋方向鍵，或按住拖曳；點欄名／列號＝整欄／整列；`Shift+空白鍵`＝整列、`Ctrl+空白鍵`＝整欄；左上角＝全部 |
| 一次填很多格 | 選好範圍、打值、`Ctrl+Enter`＝每一格都填；`Ctrl+D`＝第一列往下填、`Ctrl+R`＝第一欄往右填；複製一格貼到一整欄＝整欄都填 |
| 在選取範圍裡逐格輸入 | 選好範圍後 Enter／Tab 只在範圍裡移動（Shift＝往回） |
| 清除／複製／貼上 | Delete＝清除選取；Backspace＝這一格清空重打（Esc 還原）；`Ctrl+C`／`Ctrl+V`（跟 Excel 互通）；`Ctrl+X` 剪下＝貼上時才搬過去（Esc 取消） |
| 插入／刪除列 | 上面的按鈕，或 `Ctrl+Shift+＋`；`Ctrl+－` 只在選了整列時才刪；最後一列下面的空白列直接打字＝新增一列 |
| 尋找／取代 | `Ctrl+F`，Enter／F3 下一個、Shift+Enter／Shift+F3 上一個；`Ctrl+H` 取代（整格相符、只在選取範圍、全部取代＝一個 Ctrl+Z） |
| 右鍵選單 | 在格子上按右鍵（範圍裡＝範圍不變）或 `Shift+F10`：剪下／複製／貼上、插入／刪除列、清除內容、選整列／整欄、尋找／取代；上下鍵＋Enter、Esc 關 |
| 跳到某一格 | `Ctrl+G`（或點左上的名稱方塊）打 `C12`／`B2:D5`／列號，Enter |
| 欄寬剛好 | 雙擊欄名右邊的線（選了整欄＝每一欄都調） |
| 看是哪一列 | 下面狀態列顯示這一列的前兩欄（例如軸名、Alias）；選多格時顯示數字的加總、平均、最小、最大 |
| 存檔／復原 | `Ctrl+S`／`Ctrl+Z`（只改動過的格子的文字會變）；打字中的 `Ctrl+Z`＝取消這一格 |
| 看原始文字 | 右上「以文字開啟」；從文字切回表格：編輯器標題列的表格圖示 |

## C++ 與除錯（BCB6 的按鍵，1008）

多數按鍵只在 C/C++ 檔裡或停在中斷點時生效；Ctrl+F9／Ctrl+Shift+B（C++ 樹的視窗）、Ctrl+F2、Ctrl+Alt+B/S/W/L 不限檔案。總開關：設定 `ht9045Designer.bcbDebugKeys`。

| 要做的事 | 怎麼做 |
|---|---|
| 停在中斷點：單步／進入函式／繼續 | `F8` Step Over、`F7` Trace Into、`F9` Run |
| 停在中斷點：下／拿掉中斷點 | `F5`（游標在編輯器裡；焦點在變數／呼叫堆疊時 F5 是 VS Code 的「繼續」）；沒在除錯時 F5 仍是建置並啟動 |
| 停在中斷點：執行到游標／跑完這個函式 | `F4` Run to Cursor、`Shift+F8` Run Until Return |
| 停止全部（＝⏹） | `Ctrl+F2`：取消建置、這棵樹的 wb_* 先正常關站（最多等 30 秒，沒關才問要不要強制結束）、停這棵樹的偵錯。除錯中、建置中、或焦點不在編輯器時才有效；在編輯器裡打字時是 VS Code 的「變更所有出現處」 |
| 除錯這棵樹的機台程式時停止／重新啟動 | `Shift+F5`＝⏹ 全部停止（先正常關站，不是除錯器直接結束）；`Ctrl+Shift+F5`＝停止→重建→啟動。除錯別的程式（ctest、Node）時照 VS Code 原本的 |
| 看變數 | `Ctrl+F7` 計算／修改（選取的文字送到偵錯主控台）、`Ctrl+F5` 加入監看、`Alt+F5` 檢視（停在變數上的提示） |
| 偵錯視窗 | `Ctrl+Alt+B` 中斷點、`Ctrl+Alt+S` 呼叫堆疊、`Ctrl+Alt+W` 監看、`Ctrl+Alt+L` 區域變數、`Ctrl+Alt+C` 組合語言（CPU）、`Ctrl+Alt+F` 暫存器（FPU，在變數區的 Registers）、`Ctrl+Alt+T` 執行緒（呼叫堆疊）、`Ctrl+Alt+V` 偵錯主控台（Event Log）|
| 回到程式停住的那一行 | 命令選擇區「HTML設計: 顯示執行點」（Show Execution Point） |
| 接上已經在跑的程式 | 命令選擇區「HTML設計: 接上執行中的程式」（Attach to Process；不會關掉或重啟它） |
| 只建置不啟動 | `Ctrl+F9`（Make）；C++ 樹裡 `Ctrl+Shift+B` 也一樣 |

## 尋找視窗（Ctrl+F）

| 要做的事 | 怎麼做 |

| 找網頁、CSV、文件 | 「只找 .cpp／.h」**預設勾著**（只搜 .cpp .h .c .hpp…）；要找 .html／.js／.csv 先取消勾選（會記住）。範圍是「目前檔案」時不受它影響 |
| 註解裡的不要 | 勾「不含註解」：`//`、`/* */` 和 `#if 0` 區塊裡的不列 |

## 安全

- **預覽不會碰機台**：預覽裡所有網路連線（WebSocket、HTTP、XHR）都被擋掉。⚠ 但 F5／▶ 會建置並啟動 wb_serve（有 ADVMOT.lib 時會開 1203 卡），⏹／Ctrl+F2 會先要它正常關站；有填 hp9050Root 時還會切換機台資料夾。
- **不會改 BCB6 原始碼和 DFM**：它們只能唯讀開啟（Big5）。
- 設計畫面改的是**這一頁的 HTML 原始碼**，按 `Ctrl+S` 才寫入（新增事件會直接寫 HtdEvents.gen.cpp、wb_serve.cpp、CMakeLists.txt；機台 CSV 存檔前先備份到外掛的 csv_backup）；這些頁面由 `sync_web.py` 同步，`--apply` 會蓋掉，改之前先跟網頁作者講。
- 眼睛、鎖頭、格線只記在這台 VS Code，不寫進原始碼。
