## 0.143.0

## 0.142.0
- 新功能：**執行列**（EastSun 1001：「我需要在固定的地方可以讓我啟動、暫停、停止該軟體」，附 Visual Studio 工具列的圖）：狀態列最左邊固定有

  ⚠ ▶ 啟動的就是 F5 會啟動的那個設定——在機台上選「出貨組態」就是真的開機台軟體，跟按 F5 一樣。
- 改：**拿掉 0.141 的 ◀ ▶**（EastSun 1001：「左右可以滾輪，不是選擇檔案」——那兩顆是切換檔案）。VS Code 不讓外掛捲動分頁列，
  所以改成**分頁列捲軸加粗**（`workbench.editor.titleScrollbarSizing`＝large；第一次啟動時、你沒設過才設，設過的照你的）。

- 新功能：**側欄每一區有圖示**（EastSun 1001）：📁 方案總管、🧩 元件、🧰 工具箱、📝 屬性與事件（拖到活動列或面板時用 codicon 圖示）。
- 新功能：**方案總管的資料夾有資料夾圖示**（EastSun 1001：「資料夾也需要圖示」）。以前跟著檔案圖示主題，預設的 Seti 不畫資料夾，所以是空的；
  現在一定有黃色資料夾。

## 0.137.0
- 新功能：**專案搜尋**（EastSun 1001：「我沒辦法整個專案查詢關鍵字並列出來」）。左邊「HTML 視覺設計」多一個「專案搜尋」清單：
  一個關鍵字同時找 **C++ 移植樹、網頁、BCB6 原始碼**，每一筆照「專案 → 檔案 → 行」列出來（像 VS Code／Visual Studio 的搜尋結果），

    例如「吸嘴」在 BCB6 原始碼找得到 1,882 筆。開出來的 BCB6 檔是唯讀的（不會被存壞）。
  - 標題列：大小寫、全字、正規式（Visual Studio「在檔案中尋找」的三個選項）、複製全部結果、清除。
- 新功能：**在程式碼裡搜尋可以選範圍**（Visual Studio 的「搜尋範圍」）：編輯器裡選取文字（或游標停在字上）→ 右鍵「專案搜尋…」
  或 `Ctrl+Shift+Alt+F` → 選 **目前檔案／目前專案（這個檔所在的 C++、網頁或 BCB6）／整個方案**。
- 搜尋 4,000 多個檔約 2～5 秒；超過 5,000 筆只列前 5,000 筆並提示。可以按通知上的「取消」。
