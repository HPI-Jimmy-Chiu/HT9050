# 離線 Exit 關閉修正（20261006）

- 原因：主畫面離開按鈕遇到 live=false 只 alert 後 return，沒有要求視窗關閉；WebView2 shell 也沒有處理 WindowCloseRequested。
- 修改：離線 Exit 呼叫頂層關閉入口，頂層重新確認 live=false 才 window.close()；native 再檢查一次離線狀態後關閉 HMI。未知狀態及已重新連線不直接關閉。連線正常的停機存檔流程維持原狀。
- 關閉 HMI 不代表失聯的 wb_serve 已停止；本修正不終止控制程式。
- 驗證：node tools/test_hmi_offline_close.cjs 通過（離線、正常連線、未知狀態、父子頁重新連線競態）；JavaScript 語法及差異檢查通過。
- hmi_shell 編譯成功並部署 build_hmi_shell/ht9045_hmi.exe；連結器有既有 manifests merge 警告，UI 實際關閉交由 Jimmy 手動驗證。未啟動機台測試。
- 部署前備份 D:/AI_TempFile/hmi-before-offline-close.exe；僅關閉佔用舊版的 HMI 視窗程序以完成替換。
- 手測：F5 開啟新版，後端斷線時按離開應直接關閉視窗；正常連線按離開應仍進入原有確認與停機流程。
