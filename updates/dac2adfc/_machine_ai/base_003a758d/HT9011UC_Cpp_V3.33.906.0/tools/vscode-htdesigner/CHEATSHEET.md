# HTML 視覺設計 — 操作一覽

> 詳細說明在 README（「元件」欄標題列的 ? 圖示）。這一頁只列「怎麼做」。

## 開頁、換頁

| 要做什麼 | 怎麼做 |
|---|---|
| 開一頁 | 左邊「**頁面**」欄點一下；或 .html 右鍵「在設計檢視開啟」 |
| 搜尋頁面／元件 | 「頁面」上面的**搜尋框**打字（頁面名稱、元件名稱、型別、畫面上的文字）；清單裡點元件＝開那頁並選取。在清單按 `Ctrl+F` 跳到搜尋框 |
| 在所有頁面找元件（清單式） | 「頁面」標題列的放大鏡，或 `Ctrl+Alt+Shift+O` |
| 照某個機種顯示（例如 HT9050 的 Above9050 頁籤） | 右鍵「顯示」→「設計檢視的機種…」；預設跟 F5 一樣 |
| 在這一頁找元件 | `Ctrl+Alt+O` |
| 看 HTML 原始碼 | 標題列的 `</>`；「頁面」欄每一頁右邊的 `</>` |
| 換成新裝的版本 | 左下角狀態列「🔄 設計工具新版…：按這裡更新」，或「頁面」標題列的 🔄 |

## 選取

| 要做什麼 | 怎麼做 |
|---|---|
| 選一個 | 按一下（元件樹點一下也可以） |
| 多選 | `Ctrl`／`Shift`＋點；或在表單空白處（或表單外）**拖出框** |
| 同一層全選 | `Ctrl+A`（或右鍵「全選」） |
| 同型別全選（所有 TLabel…） | 右鍵「選取同型別（整頁）」／「（同一層）」 |
| 選上一層／下一個 | `Esc`／`Tab` |
| 選到最裡面那個／一層一層往下選 | `Alt`＋點（再點一次＝下面那一層） |

## 移動、大小

| 要做什麼 | 怎麼做 |
|---|---|
| 移動 | 拖曳（靠近別的元件會出現紅色對齊線、離鄰居 8 px 時藍色間距線；`Alt` 不吸附） |
| 微調 | 方向鍵 1px、`Shift`＋方向鍵 10px |
| 改大小 | 拉 8 個控制點；或 `Ctrl`＋方向鍵（多選時整組一起改） |
| 輸入數字 | 屬性面板的 Left／Top／Width／Height |
| 對齊／同大小 | 多選後右鍵「對齊與間距」（以最後點的為準） |
| 等距排列 | 選 3 個以上 → 右鍵「對齊與間距 → 水平等距／垂直等距」 |
| 放到容器正中間 | 右鍵「對齊與間距 → 在容器中水平置中／垂直置中」（多選＝整組一起） |
| 吸到格線 | 標題列的 `#`（格線大小：設定 `ht9045Designer.gridSize`） |

## 編輯

| 要做什麼 | 怎麼做 |
|---|---|
| 改名稱（id） | 屬性面板最上面的名稱方塊；元件樹上按 `F2`；右鍵「改名稱」 |
| 直接改元件上的文字 | 設計畫面選好按 `F2`，打字，`Enter` 確定／`Esc` 取消 |
| 剪下／複製／貼上／刪除 | `Ctrl+X`／`Ctrl+C`／`Ctrl+V`／`Del`（右鍵最上面四個） |
| 複製一份放到別的地方 | 按住 `Ctrl` 拖曳元件，放開的地方就是複製的那一份（原本的不動；Ctrl＋點一下＝加選） |
| 複製一份、錯開一點 | `Alt`＋方向鍵（1px）；`Shift+Alt`＋方向鍵（10px） |
| 拖到別的 Panel 裡 | 拖到那個 Panel 上，**放開前按住 `Alt`**（放在放開的位置） |
| 新增元件（清單選） | `Ctrl+N` |
| 取消全部選取 | `Ctrl+Shift+A` |
| 從元件上開始拉框選 | 按住 `Shift` 拖曳（Shift＋點一下＝加選） |
| 藏起／顯示控制點 | `F9` |
| 同寬／同高／同大小 | `Ctrl+Shift+1`／`Ctrl+Shift+2`／`Ctrl+Shift+9` |
| 放大／縮小一級、縮放到選取、100% | `Ctrl+=`／`Ctrl+-`、`Ctrl+0`（`Ctrl+9`）、`Ctrl+1`；按住 `Ctrl+空白鍵` 點一下＝在那裡放大（`Ctrl+Alt+空白鍵`＝縮小） |
| 等比例改大小 | 按住 `Shift` 拉角落的控制點 |
| 新增元件（放在指定位置） | 「**工具箱**」點一下 → 到畫面上點一下（或拖一個框＝連大小）；`Esc` 取消 |
| 新增元件（直接加） | 「工具箱」連點兩下，或選好按 `Enter`（同 WPF；放進選取的 Panel／GroupBox，或放在選取元件下面） |
| 放下拿起的工具 | 「工具箱」最上面的「**指標**」（或 `Esc`）；放好一個元件後會自己回到指標 |
| 設計時隱藏／顯示 | `Ctrl+H`／`Shift+Ctrl+H`（選取的元件；在元件樹＝樹上選的列） |
| 設計時鎖定／解鎖 | `Ctrl+L`／`Shift+Ctrl+L`（同上） |
| 畫面背景亮／暗 | 畫面左下工具列「背景」 |
| 放進新 Panel／解除群組 | `Ctrl+G`／`Ctrl+Shift+G` |
| 換上層容器 | 在元件樹上**拖曳**到別的 Panel／GroupBox |
| 前後順序 | `Ctrl+Shift+]` 最上、`Ctrl+]` 上一層、`Ctrl+[` 下一層、`Ctrl+Shift+[` 最下 |
| 復原／重做 | `Ctrl+Z`／`Ctrl+Y`，或標題列 ↶ ↷ |
| 存檔 | `Ctrl+S`（不按就不會寫到磁碟） |

## 屬性面板（`F4`）

| 要做什麼 | 怎麼做 |
|---|---|
| 改文字、字型、顏色、可見… | 「外觀與版面」那一區，改完按 Enter |
| 換成 BCB6 標準色（clRed…） | Font.Color／Color 下面的 16 個色塊，點一下 |
| 好幾個一起改字型／顏色／寬度 | 多選後在「外觀與版面」改（全部一起改，一個 Ctrl+Z 復原） |
| 改回 DFM 的值 | 值不一樣的列會標色；點那一列右邊的小方塊（或在那一列按右鍵）→「重設」 |
| 整個元件改回 DFM（可多選） | 右鍵「版面重設 → 全部改回 DFM」，或差異說明後面的「這個元件全部改回 DFM」 |
| 只改回位置／大小 | 右鍵「版面重設 → 重設位置／重設大小／重設全部版面」 |
| 改 HTML 的 style／屬性 | 「HTML」那一區點一下值（或雙擊）；最下面可以新增樣式 |
| 找某個屬性 | 最上面的搜尋框（空白隔開＝都要有；`Esc` 清掉） |
| 數值加減 | 屬性面板的數值欄按 ↑／↓（1），Shift＋↑／↓（10）；連按只算一個復原步驟 |
| 跳到屬性在 HTML 裡寫的地方 | 屬性面板雙擊屬性名稱（值會選起來，直接打）；或點那一列右邊的小方塊／在那一列按右鍵 →「跳到 HTML 原始碼」 |
| 輸入／取顏色 | Color／Font.Color 色塊旁的輸入框（#rrggbb、clRed，Enter）；▾＝BCB6 的 16 色和「滴管」（點畫面上的一點取色） |
| 一格一格改屬性 | `Tab`＝下一個屬性的值（小方塊、色塊不會停）；`Enter`＝寫入、游標留著（值選好，直接打下一個）；`Esc`＝放棄這次輸入 |
| 屬性換排列 | 搜尋框旁邊的 類別（預設）／名稱／DFM |
| 收合／展開一類屬性 | 點類別標題（▾ 版面…），或在標題上按 `Enter` |
| 看屬性是什麼意思 | 滑鼠停在屬性名稱上 |
| 跳到事件程式 | 雙擊事件＝直接到會執行的那個 C++ 函式；右鍵＝所有找到的程式碼；在畫面上雙擊元件＝它的預設事件（空的＝新增）；`F7`＝只開不新增 |
| 縮放、格線、對齊線 | 設計畫面左下角的工具列（－／比例／＋、全部、選取、格線＝顯示、吸附＝對齊格線、對齊線、背景）；Ctrl＋滾輪也可以縮放 |
| 選上層 | 屬性面板上方的路徑點一個上層；或 `Esc` |
| 設計畫面 ↔ 程式碼（WPF 的 Shift+F7） | 設計畫面按 `Shift+F7`＝選取元件的 HTML；HTML 或 C++ 裡按 `Shift+F7`＝回到設計畫面、選取游標那個元件 |
| 新增事件（WPF 的事件分頁） | 那一格打名稱＋Enter、雙擊那一格、或空白按 Enter（預設名稱）；下拉＝用已經有的函式；右鍵「重設」或清掉＋Enter＝拿掉連線 |
| 跳到 DFM 定義 | 屬性面板分頁那一行的「DFM」；DFM 屬性雙擊＝那一行 |

## 顯示

| 要做什麼 | 怎麼做 |
|---|---|
| 縮放 | `Ctrl`＋滾輪；標題列「符合視窗」；右鍵「顯示 → 縮放回 100%」 |
| 放大看選取的元件 | 右鍵「顯示 → 縮放到選取的元件」 |
| 平移畫面 | 按住**空白鍵**拖曳，或按住滑鼠**中鍵**拖曳 |
| 暫時藏起來（點得穿） | 元件樹的眼睛 |
| 鎖住不讓移動 | 元件樹的鎖頭 |
| 看所有元件名稱 | 右鍵「顯示 → 顯示所有元件名稱」 |
| 看哪些還沒接 | 右鍵「顯示 → 在畫面上標出接線狀態」（綠＝接了、橘＝部分、紅＝沒接） |
| 操作模式（讓頁面自己的點擊動作跑） | 狀態列「設計模式」按一下切換（網路仍然全部封鎖） |

## 檢查、比對

| 要做什麼 | 怎麼做 |
|---|---|
| 跟 DFM 比對整頁 | 標題列／右鍵「檢查與比對 → 與 DFM 的差異」 |
| Tab 鍵順序對不對 | 右鍵「顯示 → 顯示 Tab 順序」（藍＝跟 DFM 一樣、紅 3≠5＝不同、灰＝DFM 沒有） |
| 看 BCB6 原本放在哪 | 右鍵「顯示 → 在畫面上畫出 DFM 的位置」（紫色虛線框；拖過去會吸附） |
| 同一種差異一次改回 DFM | 差異清單「同一種差異」那一行的「全部改回」（一個 Ctrl+Z 全部復原） |
| 每個事件接了沒 | 標題列／右鍵「檢查與比對 → 接線總覽」 |
| 全專案哪些 Label／Panel 跟 BCB6 不同 | 「頁面」標題列 ⚠「檢查所有頁面」→「問題」面板的「資訊」項，燈泡改成 DFM 的 |
| 找 HTML 的毛病 | 右鍵「檢查與比對 → 檢查這一頁」／「頁面」標題列 ⚠「檢查所有頁面」→「問題」面板，燈泡修正 |

## CSV 表格（打開 .csv）

| 尋找 | `Ctrl+F`，Enter／F3 下一個 |

## 安全

- **不會碰機台**：預覽裡所有網路連線（WebSocket、HTTP、XHR）都被擋掉。
- **不會改 BCB6 原始碼和 DFM**：它們只能唯讀開啟（Big5）。
- 改的都是**這一頁的 HTML 原始碼**，按 `Ctrl+S` 才寫入；這些頁面由 `sync_web.py` 同步，`--apply` 會蓋掉，改之前先跟網頁作者講。
- 眼睛、鎖頭、格線只記在這台 VS Code，不寫進原始碼。
