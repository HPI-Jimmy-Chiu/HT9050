# 更新紀錄

每一版多了什麼。怎麼操作看 [操作一覽](CHEATSHEET.md)，詳細說明看 README。

## 0.111.0
- **〔程式碼〕頁不再把同一行列兩次**：監聽器的處理函式就寫在 `addEventListener` 那一行時（`function (ev) {…}`），
  以前「處理函式」「綁定位置」各列一次、內容一模一樣；現在合成一列，標「綁定＋處理函式」。
- **「HTML」那一區點一下值就能改**（跟屬性表一樣點了就打字）：以前要雙擊。雙擊照樣可以；id 照樣不能在這裡改。
- 修正：改名稱之後，偶爾選取會跑到表單、而不是改好名字的那個元件（改名時網頁的 JS 檔先改好、畫面先重畫一次，那時新名字還不在 HTML 裡）。
  現在那一次先顯示表單，但記得要選的是新名字，HTML 改好重畫時就選回它。

## 0.110.0
- **屬性表按 `Tab`＝跳到下一個屬性的值**（WPF 一樣）：以前 Tab 會停在右邊的小方塊、色塊、▾ 上，要多按好幾下；現在只停在值上。
  事件表也一樣：Tab 一格一格走事件名稱。
- **按 `Enter`＝寫入，游標留在那一格，值已經選好**（WPF 一樣）：以前 Enter 之後游標就不見了，要再點一次；
  現在可以直接打下一個值、或按 Tab 往下。數值、Caption、Font.Name、網頁事件都一樣（Enter 和離開欄位只寫一次）。
- **網頁事件（JS）也有右鍵選單**，跟元件事件一樣：「跳到程式碼」、「重設（拿掉這個連線）」。

## 0.109.0
- **屬性表每一列右邊都有小方塊**（WPF 的 property marker 是每個屬性都有）：以前只有 DFM 有寫的那幾列才有，現在每一列都有；
  淡的＝不比對（DFM 沒寫這一項、系統色、多選時值不同）。
- **小方塊的選單多了「跳到 HTML 原始碼」**（同雙擊名稱：值已經選好，直接打）；**在那一列按右鍵**也會開同一個選單
  （在文字框裡按右鍵照樣是剪下／複製／貼上）。

## 0.108.0
- 修正：沒有可編輯屬性表的元件（例如頁面 JS 產生的、原始碼裡沒有的），屬性頁看起來是空的——因為 0.102 把「DFM 屬性」預設收起了。
  現在只有上面有可編輯屬性表時才預設收起，沒有的話「DFM 屬性」直接打開。

## 0.107.0
- **事件表照名稱 A→Z 排**（WPF 的事件分頁就是照字母排）：元件事件（OnChange、OnClick、OnEnter…）和網頁事件（blur、change、click…）都一樣，好找。

## 0.106.0
- **屬性表裡 `Esc`＝放棄這次輸入**（WPF 一樣）：數值、Caption、Font.Name、顏色值打到一半按 Esc，回到開始編輯時的值，什麼都不寫。
- **正在編輯的那一列整列反白、名稱變粗**（WPF 選中的屬性），一眼看得出在改哪一項。

## 0.105.0
- **數值欄按 ↑／↓＝加減 1，Shift＋↑／↓＝加減 10**（Blend 的數值欄）：Left、Top、Width、Height、Font.Size 都可以。
  連按時數字馬上變，停下來 0.4 秒（或離開欄位、按 Enter）才寫進原始碼，**連按一串只算一個 Ctrl+Z**。

## 0.104.0
- **屬性面板上方變短了**（WPF 的屬性視窗上面只有名稱、搜尋、排列）：「DFM／HTML／複製」三個按鈕併到〔屬性〕〔事件〕〔程式碼〕那一行的右邊，
  「排列」（類別／名稱／DFM）併到搜尋框旁邊。表格往上兩行，一打開就看得到更多屬性。按鈕的完整意思在滑鼠提示。

## 0.103.0
- **雙擊屬性名稱＝跳到 HTML 原始碼裡的那個值，而且選起來**（改程式更快）：例如雙擊 `Left` → HTML 開在旁邊、
  `left:54px` 的 `54px` 已經選好，直接打新的值；`Caption` → 選好按鈕上的文字；`Font.Bold` → `font-weight` 的值；
  `Enabled` → `disabled`；輸入框的 `Left` 會找到外層定位用的 span；Panel 的字型、對齊找到標題的 span。
  原始碼裡沒寫的屬性（例如沿用表單的字型）就跳到那個元件的標籤。

## 0.102.0
- **屬性頁一打開就是一張乾淨的屬性表**：下面的「DFM 屬性」（.dfm 寫的全部屬性，唯讀）和「HTML」（位置、屬性、style）
  **預設收起**，要看再點開（會記住你的選擇）；搜尋時找到的照樣自動打開。
- 這兩區也換成跟屬性表一樣的樣子：名稱欄一樣寬、單行，類別是色帶；原本在表格下面的說明收進標題的滑鼠提示。

## 0.101.0
- **事件頁也整理成 WPF 的樣子**：兩張表都叫得清楚——「元件事件（C++）」和「網頁事件（JS）」，兩張都是同樣的兩欄（事件｜函式），
  名稱跟屬性頁對齊；網頁事件上面那一大段說明收進標題的滑鼠提示；空的欄位真的是空的
  （以前顯示灰色的預設名稱，看起來像已經有值），點進去才出現建議的名稱；「另外還有 N 個監聽器」縮成「＋N」。
- **雙擊有函式的事件＝跳過去，游標直接停在函式本體裡**（WPF 的「巡覽到事件處理函式」），可以馬上打程式；
  以前停在函式名稱那一行。新增函式本來就會停在本體裡。

## 0.100.0
- **屬性表改成 WPF 的樣子，條理分明**：固定三欄——名稱｜值｜最右邊的小方塊（空心＝跟 DFM 一樣、實心＝不一樣，點一下＝重設）。
  - 值的下面不再塞字：`DFM …` 只在**跟 DFM 不一樣**的那一列才寫（一樣的滑鼠停在小方塊上看）；
    比較長的說明（執行時隱藏、字型清單、系統色…）收進值後面的 **ⓘ**，滑鼠停上去看。
  - 類別標題（一般／版面／外觀／文字）是整條的色帶，一眼分得出段落；名稱太長會「…」截掉，不會把表格撐寬。
  - 顏色那一列只有顏色框＋顏色值；16 色和滴管收在後面的 **▾** 裡，要用再打開。
  - 最上面「和 DFM 不同」的說明縮成一行；下方的說明也縮成一行（詳細的在滑鼠提示）。

## 0.99.0
- **屬性面板分成三頁：〔屬性〕〔⚡ 事件〕〔</> 程式碼〕**。屬性頁只剩屬性（跟 WPF 的屬性視窗一樣），
  以前接在屬性下面的「網頁 JS 監聽器、網頁 JS 提到此元件、送到 C++ 的命令、資料欄位、顯示的資料標籤、程式碼用到此元件」
  都移到〔</> 程式碼〕那一頁。會記住上次看的是哪一頁。

## 0.98.0
- **顏色可以直接打、也可以用滴管取**（WPF 的顏色編輯器）：屬性面板 Color／Font.Color 的色塊下面多了
  一個輸入框（打 `#rrggbb`、`#rgb` 或 BCB6 的 `clRed`、`clNavy`… 按 Enter；打錯會標紅、不會送出）和「**滴管**」
  （點一下，再點畫面上任何一點＝取那個顏色，設計畫面上的也可以；Esc 取消）。

## 0.97.0
- **按住 `Shift` 拖曳＝拉框選取，從元件上開始也可以**（Blend：「Select by drawing a marquee: hold down Shift and drag」）。
  以前只能從空白處拉框，元件擠滿的畫面很難框。Shift＋點一下（不拖）照舊是加選／取消。

## 0.96.0
- **`Alt`＋點＝一層一層往下選**（Blend：「按住 Alt，每點一次選下面一層」）：第一次跟以前一樣選最裡面那個，
  再按一次選它下面那一層（例如按鈕 → 它所在的 Panel → 表單），到底再回到最上面。疊在一起的元件不用去元件樹找。
- **按住 `Ctrl+空白鍵` 點一下＝在那裡放大一級**，`Ctrl+Alt+空白鍵`＝縮小（Blend）；游標會變成放大鏡，點的那一點留在原處。

## 0.95.0
- **在畫面上拖曳換容器**（Blend 的 Reparent：拖到另一個 Panel 上，放開前按住 `Alt`）：元件搬進滑鼠下面的 Panel／GroupBox／表單，
  就放在放開的位置（座標換成新容器的）；一個 Ctrl+Z 復原。放開的地方還是原本的容器＝只是移動。
  以前畫面上拖曳只能改位置，換容器要到元件樹拖。分頁（TabSheet）裡照舊要用元件樹。
- 修正：**貼上、工具箱新增、元件樹拖曳「放進表單」時，會跑進表單裡第一個 GroupBox**（找表單的內框時找到的是 GroupBox 的）。
  現在只認表單自己的，放在表單的最後。（真 VS Code 的測試抓到的）

## 0.94.0
照 Blend 的快捷鍵清單補上（只在設計畫面有焦點時；F2 文字框打字時不作用）：
- `Ctrl+Shift+1`＝同寬、`Ctrl+Shift+2`＝同高、`Ctrl+Shift+9`＝同大小（以主要選取為準，跟右鍵「對齊與間距」一樣）。
- `Ctrl+=`／`Ctrl+-`＝放大／縮小一級、`Ctrl+0`（或 `Ctrl+9`）＝縮放到選取的元件、`Ctrl+1`＝實際大小（100%）。
  在設計畫面以外照舊是 VS Code 自己的意思（例如 Ctrl+= 放大整個視窗）。

## 0.93.0

## 0.92.0

## 0.91.0
- **設計畫面上按 `F2`＝直接在元件上改文字**（WPF 的 Edit control text）：選好元件按 F2，元件上出現一個文字框（字型、對齊照元件），
  打好按 `Enter` 或點別的地方＝寫進去（跟屬性面板改 Caption 一樣，一個 Ctrl+Z 復原），`Esc`＝不改。
  打字的時候設計畫面的快捷鍵都不作用；`Ctrl+Z`／`Ctrl+Y` 只復原文字框裡的輸入。
- ⚠ **改名稱不再是畫面上的 F2**（WPF 改名稱是在屬性視窗的 Name 方塊）：改用屬性面板最上面的名稱方塊、**元件樹上按 F2**、或右鍵「改名稱」。

## 0.90.0
照微軟的「XAML 設計工具快捷鍵」清單補上五個：
- **`Ctrl+Shift+A`＝取消全部選取**（多選也一起取消）。
- **`F9`＝隱藏／顯示控制點**（選取框、名稱標籤、控制點都先藏起來，看乾淨的畫面；點照樣會選取；再按 F9 回來）。
- **`Alt`＋方向鍵＝複製一份**，往那個方向錯開 1px（`Shift+Alt`＝10px）；跟 Ctrl＋拖曳一樣是新名稱、同一個容器、一次 Ctrl+Z。
  只在設計畫面有焦點時才是這個意思（在側欄按 Alt+← 照舊是 VS Code 的「上一頁」）。
- **`Ctrl+N`＝新增元件**（跳出工具箱清單選一種）；同樣只在設計畫面有焦點時。
- **按住 `Shift` 拉角落的控制點＝保持長寬比例**（Blend／WPF）。

## 0.87.0

  複製出來的放在拖到的位置、同一個容器裡，名稱自動換新的（spbSave → spbSave_2），複製的會被選取；Ctrl+Z 一次復原。

## 0.86.0
- **工具箱最上面多了「指標」**（WPF 工具箱的 Pointer）：點它＝放下拿起的工具、設計畫面回到選取（跟 Esc 一樣）。
  放好一個元件、或按 Esc 不放了，工具箱的選取也會回到「指標」（跟 WPF 一樣，不會一直停在剛才那個工具上）。
- **屬性的類別可以收合**（WPF 屬性格線）：點類別標題（▾ 一般、▾ 版面…）或按 Enter＝收合／展開；會記住。
  搜尋時，收合的類別裡找到的照樣顯示。
- **滑鼠停在屬性名稱上＝這個屬性的說明**（WPF 屬性視窗的說明）：例如 Left＝左邊到容器左邊的距離、
  AutoSize＝大小自動跟著內容、TabOrder＝按 Tab 鍵時輪到它的順序。DFM 屬性的說明後面照樣寫「雙擊：跳到 .dfm 第幾行」。

## 0.85.0

## 0.84.0
