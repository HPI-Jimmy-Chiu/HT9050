[1] Enable engineer modify bin mapping：
            開啟Engineer模式時可以修改BIN Mapping功能。

[3] Enable Site Mode Select：
           開啟可選擇單邊或雙邊測試功能；勾選後會在
        「Tool」→「Tester」選項裡出現選擇畫面.	

[4]  Enable Fix Tray Link & Half Bin Function：
         開啟FIX Tray的鏈接功能及將Tray一分為二的功能。
         此功能打開後就可以至「Tool」→「Tray Form」裡進行設定

[5]  Enable In & Out-ARM Pick IC Retry：
         開啟入料及出料手臂在吸不到IC時會再
         嘗試下降吸取IC一次的功能。
[7]  Qual Site Use Quick Mode：
         開啟Qual Site的快速模式。 

[8]  Support RC Bin：
        支援「RC」模式的分類原則，當選擇此
        項時，在主畫面右下角會出現一個切換按鈕，
        用來切換「FT」及「RC」兩個模式。
8.1   RC/FT Use Same Bin Map：
       RC/FT使用同一組BIN Mapping。

[9]  HT8080 Place To Shuttle Use Dual Drop Mode：
      在8080設備上設定當IC放置到Shuttle時可使用兩段丟擲功能，
      用於前後兩組吸嘴因外力變形造成Peith不正確(60mm)時。

9.1 Not Drop Must Up：
      此項勾選後在丟擲IC時，前後兩組吸嘴不會同時下降放置IC，
      即第一組下降丟擲IC後上升，第二組方會下降放置IC。

[11] Temperture select by device：
       高溫設定資料依產品而變。即每個產品皆有一組溫度的偏差設定
值。

[12] Temperature range：
       溫度誤差的許可範圍值。
